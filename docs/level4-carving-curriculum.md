# 专家刻滑与低姿态八字：课程设计

日期：2026-10-15。本文记录本轮课程差距、设计、证据定位与范围；页面、动画运行、来源总账和发布由对应独立记录确认。

## 目标与原始依据

用户的风格目标是低姿态八字刻滑；本站“八字”指前正后负的 duck stance，角度不必对称。CASI 四级对应的正式任务是 **Expert Large Radius Turns (Carving)**，没有名为“低姿态八字”的独立任务。课程把普通刻滑、专家板表现和低姿态应用连接起来，并分别记录条件与结果。

[S38：September 2025 Riding 指南](https://members.casi-acms.com/documents/Riding_LV4_EN.pdf)第 7 页规定：7–15 米走廊、压雪地形、专家速度，连续高效大弯；保持刻滑路径，落线前在刃上平衡发起方向变化；控制出口携带动量；弯形由立刃与调压形成，不采用枢转。7–15 米是走廊宽度，不是转弯半径。该条没有给出统一 km/h、坡角、弯数、固定脚角、身体高度或触雪标准，也未把该任务地形写为必须某个雪道等级。

第 6 页的 6–10 米中弯是正脚／反脚 **sliding** 任务，不能改称 medium carved，也不能用相应示范代替大弯刻滑证据。第 6 页总体要求三核心、四高级、一致性和有目的变化；第 8 页说明主要改变技能用量与持续时间，整体序列无需大改。

本设计实际读取 S38 第 6–8 页；复用此前已经读取的第 3、5 页反馈与评分边界。另实际读取 S16 Reference Guide 第 44–45、49–52、55–56、58–59、61、97–98、119–120、155、181–182 页：

- p.119–120 的 Expert Carving 直接提供精修入口：已有较广泛压雪刻滑基础，按中立、建立抓雪、加载与引导组织，变化弯形、动作量和持续时间。
- p.51–52 区分屈伸启动与收住，允许多种过渡，并反对用过度屈伸制造压力。
- p.58 的四高级能力用于实际板表现；本课不将其变成固定姿态。
- p.44–45 的稳定与活动余量必须一起考虑；duck 不无条件优于其他刻滑设置。
- p.155 支持前后刃关节组合不同；不从示意照片提取统一角度。
- p.181–182 支持个人、器材、用途与舒适性匹配，duck 定义及靴居中检查。

p.120 的身体旋转、反旋转探索是技能发展方法；身体相对朝向变化与板的枢转滑移是不同层次，不能用此推翻正式任务的无枢转要求。版本交叉核验与完整来源边界见[官方标准研究](level4-carving-official-standards.md)。

## 现有覆盖与实际缺口

七门既有 carving 课程分别覆盖：单弧、浅弧连接、刻／搓选择、弯形控速、路线导航、结果自查、duck 低位连续与恢复。相关高低、成角、靴居中、两侧差异和扫尾诊断课已经有正常高度基线、退阶、本站练习量与逐结论来源。它们需要继续使用，不为新增专家层全部重写。

| 缺口 | 现有内容为何不足 | 本轮处理 |
| --- | --- | --- |
| 官方终点映射 | `v20-path` 只有“性能来自时机”等一般进阶方向，未列 Expert Large Radius 的具体任务 | 扩展现有导航课，明确官方条件、当前基线与低位应用区别 |
| 完整专家弧线训练 | 单弧和浅弧建立窄痕，但没有落线前建立、刻滑路径与出口携带动量的连续阶梯 | 新增 `s-carve-expert-arc` |
| 刻滑任务中的加载／释放 | 高低课和单侧伸腿课提供局部工具，不能自动证明两向、整段、专家条件中的板表现 | 新增 `s-carve-expert-pressure`，单项调整后接自然弯，再连接并撤提示 |
| 变化与低位应用的条件隔离 | 原 `s-duck-low-linked` 主要在熟悉缓坡，不能将其结果直接外推专家任务 | 新增 `s-carve-expert-variation`，变化条件与降低分趟做，低位不设为普通专家必修 |
| 完整证据与外部反馈 | 原自查没有独立专家刻滑多趟协议和相应真人任务观察 | 新增 `s-carve-expert-review` 与独立协议；真人卡由实际观察后接入 |

## 最小课程增量

新增四课，修改三门原课，增加五个结果能力节点。没有新增动作几何或动画引用。

| 课程 | 可执行学习链 | 可观察结果与退阶 |
| --- | --- | --- |
| `s-carve-expert-arc` | 完整基线 → 两向各一次释放／跨侧／渐进建刃调整 → 接自然弯 → 单独调一个出口 → 撤提示 | 落线前新弧、板尾跟随、出口与下一弧一起改善。卡刃、扑肩、横扫或速度失控则回小幅可控弧 |
| `s-carve-expert-pressure` | 定位异常响应之前阶段 → 原弧小调时机／持续时间 → 两向分别验证 → 连成短组 → 起中末复看 | 路径、释放与下一弧选择保持；不能用横扫代替跳动、用最低位代替余量。异常上抛、疼痛或装备线索先停 |
| `s-carve-expert-variation` | 先正常高度基线 → 一项条件变化后重建控制；或另选正常—稍低—恢复 → 同条件复测 | 变化后仍可保持刻滑目标或主动退出。低位未到官方速度仍可记该条件进步，不能补写官方达标 |
| `s-carve-expert-review` | 任务匹配 → 完整原片与条件 → 逐项证据 → 另一趟复测 → 外部反馈 → 回一项训练 | 每个判断能回到时段与条件。缺条件、遮挡或任务不匹配就保留未观察；不生成自动分数 |

原课只作必要衔接：

- `v20-path` 保留基础与低姿态路线，新增官方目标和基线、专家课入口，挂共享刻滑复盘协议。
- `s-duck-low-linked` 保留原动作、练习地形和剂量；追加专家入口，并说明熟悉缓坡不自动覆盖专家任务。
- `v-toe-touch-criterion` 增加基础自查与专家任务的范围区别，链接专项复核。

所有新增组数、步骤、起终点、比较和退阶均标为本站建议。Arc 基线 4–6 弯，再做两向单项调整和撤提示；pressure 基线 4–6 弯、两向各两次单次调整后接自然弯，再最多两组短连弯。Variation 的条件迁移与低位应用二选一，不要求同日凑齐：前者从 4–6 弯基线到新条件 2–4 个熟悉可控弯确认；后者正常、稍低、恢复各四弯。质量停止优先于完成数量。

## 能力路线与前置

沿用 `carving` target 及现有阶段，追加：

`adjustable-carved-turns → expert-carve-reference → expert-carve-arc + expert-carve-pressure → expert-carve-variation → expert-carve-review`

前三级位于 `expert-refine`，后两级位于 `expert-verify`。不增加新列，不改变小回转前置。

`duck-height-control → duck-low-linked-carves` 保留为已有风格分支。**只有选择低位应用时**，才要求完成该分支与装备核对；它作为 variation 的辅助关系和条件前置出现，不成为普通 Expert Large Radius 的强制站姿门槛。低位未练或不适用时，相应观察项可保持未观察。

`expert-carve-variation.lessons` 只列新 variation 课；低位基础课通过辅助能力和相关课程入口衔接，避免基础课页面聚合出专家弧线与调压前置。同一课程可用于建立多个能力，课程页汇总“前置能力”时排除本课直接归属的节点，防止把本课自身建立的能力又显示为入门门槛。这只调整课程页的汇总展示，能力图中的节点依赖与完成状态判定保持不变；回归测试覆盖外部前置保留、直接归属入口保留及原依赖继续生效。

## 独立复盘协议

协议 ID 为 `casi-l4-carving`，独立于 `casi-l4-short`。`v20-path` 与四门新课共享它；原有小回转记录不会被套入刻滑任务。`fieldHints.corridor` 明确最终任务的 7–15 米，并提醒训练可以先用已掌握范围；速度和本次变化也有专属提示。

十二项观察 ID 与用途：

| ID | 用途 |
| --- | --- |
| `task_conditions` | 官方走廊、压雪与专家速度的实际条件和确认方法 |
| `centred_mobile` | 两腿和沿板长位置可调整，不用固定50/50或最低位代替 |
| `lower_body_guidance` | 下肢组织立刃、调压与跨侧，不横扫板尾，身体不冻结 |
| `working_edge_balance` | 两侧工作刃均可支撑和释放，非外观镜像 |
| `arc_to_arc` | 落线前建立有效新弧并接续下一弧 |
| `carved_path` | 维持刻滑路径，无枢转扫尾；滑移退出另记 |
| `strength_flow` | 起中末强而可动，两向连续 |
| `loading_deflection` | 加载与释放有目的，区分可见响应与未测的力学量 |
| `exit_momentum` | 出口携带动量且保留下一弧选择，不等于无限加速 |
| `steering_versatility` | 在刻滑目标下调整立刃／调压的用量、时机和持续时间 |
| `variation_transfer` | 本站单条件迁移与复测，不扩写成所有雪况已通过 |
| `duck_low_recovery` | 本站风格应用：正常—稍低—恢复，不充当官方评分项 |

协议整体是本站观察组织，不是官方评分 grid。仍使用“未观察／需发展／本条件可重复”和逐项证据；另记日期、地形、雪面、速度、走廊、装备、站姿、变化、录像索引、反馈和下次任务。官方条件、正常高度表现与低位应用分趟保存，不能用一趟较快表现替另一趟低位补条件。

官方第 5 页的两次计分机会、两位考官与每项至少 6/10，只用于说明正式制度；资料未明确的两趟合成算法不补写。录像学习、本站自查与官方结果确认不是同一件事，完整 Level 4 资格亦不由本专项授予。

## 真人与现有动画分工

本补丁不制造 `videoStudy` 或已看帧。主代理负责定位官方 Carving 片段并实际观察，不能拿视频中的 Medium 滑移段代替。复核课先提供任务识别与证据方法，视频卡及其来源结论在观察后接入。固定器角度看不清时保留未知，不能因低位外观认定示范者为 duck。

既有 `duck-carve / linked-duck-carve` 用于正常／较低／前刃探胸的身体关系对照；既有单侧与压力任务提供局部练习入口。它们没有专家大弯真实速度、7–15 米任务标定、足底压力、板弯曲、弹性回能或全部接触动力学，不改名为专家任务验证。本轮未新增作者动画引用，四课通过相关入口复用，并由实际官方刻滑示范支持专家任务观察。

## 交付与验证边界

补丁为 `.validation/level4-carving/curriculum-patch.json`，格式 `level4-carving-curriculum-patch-v1`，含四个完整 `appendLessons`、三个按字段替换的旧课修改、独立协议、五节点、模块和课程目录修改。来源对象继续复用 S38、S16、S40 等；主代理补视频卡，来源代理逐字段审查最终集成正文。

结构核对记录 `.validation/level4-carving/curriculum-structure-check.json`：课程、来源、课内引用和节点均可达，requires 无环。此项仅确认数据关联，不等于来源主张、教学画面、雪上试教或发布通过。最终静态内容复读、来源账、浏览器和发布须分别记录，不能通过刷新旧哈希抹掉历史证据边界。
