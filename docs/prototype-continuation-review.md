# 独立原型与离线入口补核

2026-10-15，基于当前构建实际打开独立 `/3d/`。correct、error、drill各在regular/goofy下采样13时刻，共78帧，6张联系图均逐张实际观察。时刻：0、.08、.125、.17、.25、.42、.5、.58、.625、.67、.75、.92、接近1；使用默认斜视，不把它称作每一帧或所有视角覆盖。

- correct：两向都显示弧内屈曲与过渡相对伸长；板和身体方向随整弧改变。两惯用脚的装备身份、路线和角色颜色对应，未见仅镜头翻转的标签矛盾。
- error：与correct可区分，板轴变化更集中、弯内朝向与移动路线夹角更显著；仍保留两脚固定和关节连接。不把全部滑移都归为错误。
- drill：同刃等待占比明显，转换后恢复另一刃侧滑，最后回到与起始相容的身体关系。侧滑方向箭头与板长轴不同，不误读为纵向直滑。
