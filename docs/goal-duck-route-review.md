# 低姿态八字刻滑：专项审查、来源和示范单元

日期：2026-10-15。审查基线为 `3286885`；范围是刻滑与其直接依赖的姿态、转换、装备和纠错。本文记录内容/源码审查与原始资料阅读；动画新增实现、数值检查、浏览器观察、部署各由对应记录证明，不能从本文推定通过。

## 已确定的定义与教学边界

本站“八字”采用前脚正角、后脚负角的 **duck stance（鸭式站姿）**；两脚角度不必绝对值相等，不指数字 8 的滑行路线。正常高度指本人舒适、关节可继续调整的参考站位；低姿态指在这一基线上适量增加屈曲、降低身体且保留余量。既没有统一的最低高度，也没有统一脚角、高背角、刃角或前后脚压力比例。

普通刻滑先以板表现、路线与退出能力建立基线。低姿态是本产品的重点风格分支，不是对所有刻滑者的升级要求。完成大坡搓雪、能“走刃”或能 ollie 不能替代本课前置自测；反脚尚不能刻滑，也不阻止在已稳定的正脚方向练本课。

### 分歧如何处理

- AASI 不同级别刻滑任务列出的屈伸与沿板长调节重点不同；CASI 也描述多种减重。本站默认动画选温和伸展过渡以便比较高度，是**教学简化／作者编排**，不称唯一正确策略。
- CASI 入门刻滑强调双脚总体均衡；AASI 部分进阶任务描述随阶段的前后变化。适用任务不同，本站保留两脚可调与板尾跟随这一共同目标，不规定“始终前重”或固定百分比。
- 厂家把双正列为深弯用途之一，不代表 duck 无法刻滑；站姿不同会改变活动空间。本课只在 duck 范围内讨论，其他风格需独立校核。
- 正常高度→稍低单弧→较低连续的课序、组数、自查门槛均为**跨来源归纳及本站教学建议**。尚无依据声称它是某机构统一的“低姿态八字”课程。
- 原始教材照片已实际查看；本专项没有观看官方视频帧序列，也没有完成教练实拍逐帧或动作捕捉标定。既有课程 `time` 只是原视频主题索引，不能当本轮动画校准证据。

## 完整示范单元与动作规格

课程稳定 ID 为 `s-duck-low-linked`，完整可集成对象保存在 `.validation/goal-audit/duck-content-patch.json`，集成后以 `content.json` 为唯一课程正文。补丁是交付中间物，不公开分发第三方完整教材，也不把本地补丁存在写成网站已更新。

### 学习者实际怎样使用

1. **前置自测**：正常舒适高度的双侧单弧与连续窄痕、计划出口、主动转搓雪停止。欠缺处回 J 弧／浅弧／弯形课。
2. **条件**：熟悉宽缓、抓地均匀、可见停止区；核对 duck、靴居中和舒适膝髋。雪况差或空间不足时改练已有控速。
3. **分解**：正常高度单弧 → 该侧弯中略降 → 恢复。前刃看膝髋一起到脚尖侧，后刃看膝髋折叠、骨盆脚跟侧与胸廓回板；不借摸雪改变身体关系。
4. **连起来**：旧刃后段保留余量 → 渐减旧刃并组织身体 → 短暂近平板 → 新刃渐建 → 弯中略降低 → 下一次释放。默认沿用温和伸展转换；不同时重学回收。
5. **练习量**：本站建议每侧 2–3 个单弧，再每组 4–6 弯做正常—稍低—正常对照；组间停稳复看。连续两组通过才只改一项条件，疲劳或控制下降就结束。
6. **自检**：两侧窄痕、走廊和控速、双向释放、活动余量必须一起成立；可恢复正常高度并主动滑移退出。不以手碰雪、读完课或某帧很低勾选。
7. **录像**：从安全道边拍侧后方完整两个弯，侧面补关节关系；保留旧刃后段、近平板、新刃建立、前后刃弯中与下一次释放。单帧不作验收。
8. **诊断回退**：降低才扫尾，先恢复高度后看髋是否滞留、是否折腰/后坐或拖靴；只在换刃失稳，先查释放与余量；组末加速回弯形课；装备疑点先查装备。
