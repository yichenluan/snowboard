直接依据为 [S38现行 Riding Guide](https://members.casi-acms.com/documents/Riding_LV4_EN.pdf#page=7)（September 2025）p.7 Expert Large Radius Turns (Carving)：7–15米走廊、压雪、专家速度、落线前刃上平衡发起方向改变、保持刻滑路径、以立刃与调压形成弯形并控制出弯携带动量。p.6总体要求及p.8说明技能用量、持续时间和有目的变化。[S16 Reference Guide](https://members.casi-acms.com/documents/Ref_Guide.pdf#page=119)（©2021）p.119–120提供已有刻滑基础上的专家教学；p.51–58解释压力、时序与高级能力；p.155支持两刃不同身体组织。实际读取方法与适用边界沿用本轮已读的[官方标准研究](level4-carving-official-standards.md)及[逐字段来源复核](level4-carving-source-claim-review.md)。本次未声称另观看视频；真人对读仍为主任务的[13帧记录](level4-carving-video-observation.md)。

任务与程序是本站编排。10米示意通道处于官方范围内，但播放时长不用于换算或判定专家速度。专家任务没有规定duck、低位、摸雪、统一角度或本片六弧；共享人物仍用原来前正后负的示意装备，不将其升级为官方站姿。

## 接入契约与所有权

子任务只新增下列文件，不编辑 `content.json`、注册表、共享动作入口、播放器或场景：

- `lesson-player/expert-carving.ts`
- `tests/expert-carving.test.ts`
- 本规格

主任务接入 `type: "expert-carving"`，模块导出：

- `supportsExpertCarvingLesson(config)`：仅接受以下明确task/variant；拒绝旧duck任务、不兼容的posture/transition/turnShape、非法fromEdge和`pressureDiagram:true`。
- `sampleExpertCarvingLesson(time, config, stance)`：与既有`LessonFrame`一致；返回同源state、阶段、`moving:true`、示意corridor。
- `expertCarvingVariants(config)`：同进度切换的合法选项，弧线任务只有一个选项。
- `expertCarvingDurationMs(config)`：默认24,000ms，最低12,000ms，仅为播放设置。
- `expertCarvingCorridor`：宽10米、坡下范围0–72米的几何示意。

配置表：

| task | variant | 建议展示 |
| --- | --- | --- |
| `expert-carve-arc` | `linked` | 弧线与阶段，`trackDiagnostics:true` |
| `expert-carve-release` | `coordinated` / `late-flex` | 同进度比较，可用`legLengthDiagram:true`；不得启用压力图 |
| `expert-carve-adaptation` | `normal` / `lower-recover` | 同进度正常参考与正常—稍低—恢复比较 |

`fromEdge`表示第一弧建立的目标刃，默认`toe`；不是旧刃。`regular/goofy`调用共享镜像，保留原前后脚、固定器及身体身份。时间接受0–1，非有限值回0，超界夹取。末态仍在滑行，不能作为停车示范。

三个任务围绕同一独立专家刻滑基准组织，弧线参考、时序参考和正常高度参考共享此基准，避免为了增加数量制造不同“标准姿态”；它们分别回答弧线、时序和恢复问题，并非五种独立雪上技巧。新轨迹从未调用旧`carving.ts`或duck采样器。

## 几何、时序及对照变量

六弧各有局部进度u，左右工作刃交替。横坡位置按独立的平滑空间曲线生成，坡下连续推进；路线解析导数给出移动方向与板轴，不先画路线再独立转板。落线事件为局部u=0.5，此时实际横坡速度分量为零。板角按同一工作刃顺序渐建、渐减，近平板阈值采用共享输出的0.008rad，按钮放在目标区间内避免浮点归入上一状态。每弧六个阶段，加一个末态标记，共37个阶段入口。

时序参考实际平均髋踝距离在弧内由约0.810米到0.755米再恢复；偏晚对照将这一包络后移0.14个弧段，不改变板/路线/刃角/靴筒和释放事件。两腿并非被平移到新位置：仍由固定靴底、固定胫骨与股骨和髋宽求解，胸廓随腿长组织。它不是纯骨盆位移，也不是独立的受力求解。

高度对照只在中间两弧增加实际腿长缩短，前刃与后刃分别编排；新增项在两弧边界及一阶导数均归零。实采中间弧峰值骨盆相对正常参考分别低约3.91cm和7.72cm。这个非对称量服务“稍低仍可恢复”的可观察目标，不是人体标准；两侧不要求同高或镜像。镜头不得放大到掩盖真实小幅变化。

作者参数包括横坡幅度4米、每弧坡下12米、板角峰值28°、不同侧的腿长附加量、靴筒12–18°及24秒播放。它们没有从13帧视频量取，也不是CASI处方。`edgeLoad`仍只是共用状态中的示意强度，不得显示成牛顿、足底压力或合力。

首尾位置只沿坡下相差72米，姿态、方向和运动趋势可接续；六弧可周期播放，包含恢复段的高度任务也真实回到正常参考。重播的世界位置回置由播放器处理，不应描述为雪上停车。全部阶段循环仍须由播放器处理末态非零区间，主任务实际从100%验证。

集成时新增`routeWindow`，按世界坡下区间提供当前弧及前一弧的局部路线，完整六弧仍可展开；同一采样状态供两图使用。末态阶段提供`replay.from=5/6`与“末弧完整衔接”标签，100%开始分段重播时重看最后完整一弧。实际画面和交互验证范围见[根任务审阅记录](level4-animation-release-review.md)，本页下方验收要求不自动转成全部通过。

## 深度交互：表达与验证的边界

把专家知识写进卡片不意味着已有动画能解释它。新增任务使弧线、动作时序与恢复有了可检查的输出，但仍不能替代速度、雪面抓地、板材响应、压力或学员真实连续表现。若画面审阅发现某个关系不够清楚，应修任务幅度、阶段或观察提示，不能靠“专家”名称和文字解释把不清楚的画面判为通过。
