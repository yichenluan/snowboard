可复用原型的5个edge-change-up窗口：前到后`sampleMotion(.34+.5*u,"correct",stance)`，后到前`.84+.5*u`。平板分别位于.59/1.09；旧phaseName不准确，包装层按实际边事件重生成，不直接抄阶段。

压力不能由髋高度生成数值。原地简化条件下，上升加速趋增、上升减速趋减、下降加速趋减、下降减速趋增；静态保持没有同样附加加速度。显示骨盆曲线要叫骨盆；COM使用state.com也只是分段估计，不是压力中心或实测受力。雪上还受弯形、速度、地形影响。

`PlanarDiagram`是随板坐标，不能叫固定雪面参考。`transitionReference:"snow"`需要同源、固定坐标的板/身体轨迹及高度对照。回收的较平顺身体路径必须来自动作状态，不能渲染阶段锁胸廓伪造。

已实现9引用的说明：诊断课显式fromEdge:"heel"且不提供相反方向；phase-study显式原地平板，并以state.com高度的速度峰值确定加速/减速阶段；伸展换刃按state.edge确定旧刃/近平板/新刃，原型阶段名不直接继承。原地与转换证据面板分别说明所画的量。

## 已执行验证（9引用）

- 工程测试同时约束9个已接管与6个未接管引用；部分类型通过variant门控，不能把pressure-flex/extend全类型计作完成。
- 原地高度范围0.97445–1.03682m，下降减速事件21.5909%、上升13.8182%；时刻由实际高度数值求得，不采用关节曲线的中点。骨长、静止脚位、板面支撑投影、保持与恢复均采样检查。
- 两向近平板区间48.9388%–51.0612%；末态仍滑行。两前脚方向全周期脚位、装备、骨长、连续性与接触检查通过。
- 实际看过原地屈伸保持/减速/恢复、靴近景、实体与骨架；前换后慢放和后换前正常播放至末态；固定雪面投影与阶段、轨迹对照。窄屏和禁WebGL两类新图实际可读。详细执行记录见[播放器审阅](lesson-player-review.md)。
- 上述数值是作者模型一致性，不是实测关节、压力或教学认证；尚未完成实拍逐帧标定。

仍待实现的6引用：后刃弯中伸展、前刃弯中吸收、低位过渡、两处回收过渡及时机对照。它们不能借本批原地或伸展窗口替代。其文案应分别说明同刃、身体降低、板回收和单变量时机。
