5个edge-change-up引用实际复用的原型窗口：前到后`sampleMotion(.34+.5*u,"correct",stance)`，后到前`.84+.5*u`。平板分别位于.59/1.09；旧phaseName不准确，包装层按实际边事件重生成，不直接抄阶段。

压力不能由髋高度生成数值。原地简化条件下，上升加速趋增、上升减速趋减、下降加速趋减、下降减速趋增；静态保持没有同样附加加速度。显示骨盆曲线要叫骨盆；COM使用state.com也只是分段估计，不是压力中心或实测受力。雪上还受弯形、速度、地形影响。

`PlanarDiagram`是随板坐标，不能叫固定雪面参考。`transitionReference:"snow"`已由`diagnostics.tsx`提供同源、固定坐标的板/身体轨迹及高度对照。回收的较平顺身体路径必须来自动作状态，不能渲染阶段锁胸廓伪造。

第三批9引用的实现说明（2026-10-14）：诊断课显式fromEdge:"heel"且不提供相反方向；phase-study显式原地平板，并以state.com高度的速度峰值确定加速/减速阶段；伸展换刃按state.edge确定旧刃/近平板/新刃，原型阶段名不直接继承。原地与转换证据面板分别说明所画的量。

## 第三批历史验证（9引用，2026-10-14）

- 第三批当时的工程测试同时约束9个已接管与6个尚未接管引用；后6项随后在第五批接入。部分类型仍通过variant门控，覆盖全部现有引用不等于支持任意新变体。
- 原地高度范围0.97445–1.03682m，下降减速事件21.5909%、上升13.8182%；时刻由实际高度数值求得，不采用关节曲线的中点。骨长、静止脚位、板面支撑投影、保持与恢复均采样检查。
- 两向近平板区间48.9388%–51.0612%；末态仍滑行。两前脚方向全周期脚位、装备、骨长、连续性与接触检查通过。
- 实际看过原地屈伸保持/减速/恢复、靴近景、实体与骨架；前换后慢放和后换前正常播放至末态；固定雪面投影与阶段、轨迹对照。窄屏和禁WebGL两类新图实际可读。详细执行记录见[播放器审阅](lesson-player-review.md)。
- 上述数值是作者模型一致性，不是实测关节、压力或教学认证；尚未完成实拍逐帧标定。

## 第五批历史实现与验证（其余6引用，2026-10-14）

- `pressure-advanced.ts` 独立生成同刃单弯、较低身体转换、回收转换及时机研究；只复用装备与骨长求解，不调用原型周期替代任务。
- 同刃伸展/吸收保持指定刃，沿弧线渐停，100%保留工作刃；停止姿态另按估计质心沿板宽对工作刃投影求解。沿刃偏移分别为3.07/2.41cm，位于板长内。这里只证明运动学支撑投影，不计算弯中真实压力。
- 吸收从24%到62%连续缩短髋踝平均距离约3.905cm。测试核对单调缩短和可观察变化，没有为了满足原先无来源的4cm阈值夸大动作。
- 降低示例的COM高度变化约11.7–11.9cm；回收约5.5–6.1cm。回收的板横向范围70cm、COM横向约6.75–8.45cm，身体未冻结。两例路线及幅度不同，只用于辨认机制，不能比较同条件效率。
- 新刃分别于52.9593%/52.2101%建立，53%开始恢复腿长；两向阶段由实际刃事件求得。前后刃适合的端点腿长不必相同，文字不再声称完全恢复起始腿长。
- 时机三档的实际髋踝平均距离包络为0.770–0.795m，启动12%/22%/32%，幅度和时长相同，只作时间平移；板路径、刃角和移动方向逐点相同。没有声称每个关节轨迹也原样平移，或哪一档天然更好。
- 新增4项行为回归，连同全站44项通过；两前脚和两向连续性、接触、固定脚位、骨长与控制变量均采样。实际画面和环境检查范围见[播放器审阅第五批](lesson-player-review.md)。仍未完成连续实拍逐帧标定。
