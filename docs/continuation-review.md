## 当前学习路径

两条路线沿用上一轮已实施的能力闭环，本次补齐可执行的计量及证据：

- 搓雪小回转：双刃停止与可控连弯自测 → 同刃侧滑接单弯/较宽圆弯 → 释放、下肢转向与新刃建立 → 缩短等待或逐级缩弯 → 连续小回转 → 根据路线、节奏及两侧差异退阶。温和伸展、屈曲、回收是有条件的分支。
- 低姿态八字：duck前正后负定义与装备/舒适活动检查 → 正常高度两侧单弧与连刻滑 → 单侧调低仍能退出 → 两刃低位与连续转换 → 高度、路线、余量共同验收。回收选修，触雪不是达标条件，反脚并行但不自动认定已掌握。

入口：[小回转](https://jinke.me/snowboard/#lesson=s-short-integrated)、[低姿态duck](https://jinke.me/snowboard/#lesson=s-duck-low-linked)。
