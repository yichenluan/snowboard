# 开放朝向、自然站姿与学习路线：全站独立复核

2026-10-16。范围：当前 **118门课程、150项动画引用**，并核对独立三维原型及31个术语。本文记录本轮实际完成的来源、源码、数值、有限页面图审和工程检查；发布结果独立列在文末。历史[JSBA体系对比](jsba-carving-comparison.md)与[上一轮姿态复核](jsba-posture-review.md)保留各自版本和证据范围。

本轮最明确的缺口是两门“开放后刃”课：文字要求比较自然与较开放的肩髋朝向，原动画却只演示前后位置微调。本轮已补上真实朝向对照。与此同时，自然位、高性能开放和反向旋转应按任务分别教学，不能把所有课程统一成一种开髋外形。

[150引用逐项分类](open-stance-scope.md)保留本轮修改前基线与正文定位：明确开放13项、开放／自然对照5项、阶段性开放1项、自然可调98项、无关／反例33项。明确开放的13项包括12个JSBA作者示范契约和一个原地方向任务，幅度仍各自编排；这些数字不表示JSBA要求所有滑手使用同一开放站姿。

## 1. 先分清朝向、脚角与转动过程

| 概念 | 本站此处的含义 | 容易混淆的地方 |
| --- | --- | --- |
| 开肩 | 胸廓相对雪板更朝板头方向打开；观察胸前正面 | 转头、抬手或两肩连线的朝向都不能单独证明胸廓正面朝哪边；这里不是耸肩或肩关节拉伸 |
| 开髋 | 骨盆正面，也就是肚脐所代表的方向，更朝板头打开 | 不是把膝硬拧向某侧，不是增加站距，也不等于身体已经跨到新刃 |
| 自然朝向 | 结合脚角、任务与个人活动范围，能继续屈伸、调刃和换侧的参考关系 | 自然位本身可以略开；不等于肩髋必须平行雪板，也没有所有人通用的肩角 |
| 转头 | 头和视线独立观察路线、出口与周围 | 头已看向板头或坡下，不代表胸和骨盆已经跟着转动 |
| 八字／duck | 前脚固定器为正角，后脚为负角，不要求绝对值相等 | 不是路线画数字8，也不决定唯一胸髋朝向；双正角姿态不能直接搬给八字 |
| 开放弯 | 一个弯的出口仍较朝坡下，和较闭合、更多转向横坡的弯相对 | 这是路线形状，不是开放站姿；`turnShape=open`不是身体开向开关 |
| 反向旋转／counterrotation | 在同一时段、同一雪面参照下，上下身同时朝相反方向转动 | 静态开肩、上身少转、上下身有夹角、先蓄扭再释放，都不能单凭最后造型判成同时反向 |

胸前与骨盆朝向也要分别观察：只转胸不等于骨盆已参与。身体朝向是“朝哪里”，跨板换侧是“身体相对板宽移动到哪里”；前者不能替代后者。

## 2. 一手教材并不要求所有任务同一种站姿

### CASI：自然参考、分离和同时反向分别解释

本轮重新读[CASI Reference Guide](https://members.casi-acms.com/documents/Ref_Guide.pdf)本地192页版本的相关文字，并查看原页照片与图示。这里的页码为印刷页码，与本轮PDF页码一致。

| 定位 | 资料实际支持 | 不能据此推出 |
| --- | --- | --- |
| p43，Neutral Position | 中立参考位的肩髋与前脚角相适配，关节可动，视线独立看行进方向 | 不要求肩髋完全横向，也不是所有动态阶段固定同一姿态 |
| p45，Stance & Binding Set Up | 脚角、站距影响身体朝向和活动；应结合滑行目标与地形试调 | 不从照片或某个固定器角度推出所有人的统一开髋值 |
| p47–48，Pivot | 下肢引导、上身旋转与同时反向是不同运动工具；反向旋转可用于快速调整 | 不把所有开肩判错，也不把普通搓雪弯都教成猛甩肩 |
| p59，Separation／Steering | 上下身可有不同动作与相对朝向；弯中上身朝板头的分离可用于特定性能目标 | 分离不等于肩膀锁死，更不等于每一时刻都在同时反向旋转 |
| p155–156，人体与运动 | 前后刃关节组织不同；反向旋转、预先蓄扭和下肢追转分别讨论 | 两刃不机械镜像，后刃向脚跟侧屈髋也不等于沿板长坐向板尾 |

[CASI Level3 Teaching Module](https://members.casi-acms.com/documents/TeachingModule_LEVEL%203%20COURSE%20GUIDE-EN.pdf)印刷p15的Using counter-rotation，是高级调速与转向多样性案例。它支持本站反向调速专项，不支持“所有短弯必须反拧”。[Asymmetry in Snowboarding](https://casi-acms.com/national-tech-team-articles/asymmetry-in-snowboarding/)则提供两向常见失配的观察线索；这些线索不能改写为每个人必然发生的错误。

### SBINZ：高性能阶段明确教合适的开放

本轮从官方重新取得并实读[SBINZ Instructor Manual 2017英文原版](https://www.nzsia.org/wp-content/uploads/2017/06/SBINZ_Manual_2017.pdf)，不依赖中文译词倒推原意。这是2017公开手册，不能冒充未取得的新版本全文。

| 定位 | 资料实际支持 | 适用边界 |
| --- | --- | --- |
| 印刷B/10–B/11，PDF85–86 | 基本站姿结合脚位、工作刃和个人差异，保持可以移动和返回的参考位 | 不是要求初学者复制高性能低位 |
| **印刷B/13–B/14，PDF88–89**，High Performance Stance | 明确写肩髋更“**more rotationally open**”，经常参考前脚角；合适时可扩大全身活动，服务立刃、转向和压力调节 | 同页强调因人、因任务而异，不是越开越好，也不是所有课程都用同一个角度 |
| 印刷B/21–B/24，PDF96–99 | 上下身旋转、whole body、counter、separation和anticipation分别定义 | 同时反向、相对朝向和预先准备不能混成同一个“开髋”动作 |

因此，准确结论是：**官方教材既教可活动的自然参考，也在高性能任务中鼓励适当开放。**本站可据此发展任务对应的开放姿态；JSBA个人低位八字示范的大幅开放，仍不能反推成所有基础课的统一模板。

### MIRATORI：个人方法与字幕术语保留归属

本轮重读了澤田剛志本人公开视频的已保存英文字幕，并实际查看四张已保存有效帧：S55的347.240／389.280秒、S54的5.433秒、S52的195.033秒。**本轮没有重新播放原片，没有逐组重新取完历史窗口，也没有重新听辨日文原音。**

[S55：八字开髋方法](https://www.youtube.com/watch?v=R7xBPS_axN4)可供定性观察胸、骨盆和前后腿配合。其英文字幕0:58、1:07及6:27使用counterrotation描述本人前刃方法；应保留本人术语，不能直接套成CASI的搓雪speed check，也不能为统一概念而说他从未使用这个词。

[S54：后刃方法](https://www.youtube.com/watch?v=FookVR1Ojuw)字幕2:09–3:26、5:43–6:21、7:34–8:24讨论骨盆、后腿与前膝的配合；[S52：前刃方法](https://www.youtube.com/watch?v=TwjZvBUY7hU)字幕8:38–10:10讨论本人前刃避免继续过旋拉板。字幕与有限帧可支持具名方法的定性归纳，不能推出统一脚角、膝角、压力、完整转换先后或机构要求。“脚向外”也不能在模型中解释成移动固定脚位或把板真的踢横。

## 3. 按任务决定开放、自然或对照

| 课程／任务 | 合适的朝向原则 | 本轮审读判断 |
| --- | --- | --- |
| `v-heel-open-rear-foot`、`v-heel-open-loading` | 文字既要求自然／较开放对照，动画应实际提供可比较的胸髋朝向 | 原映射缺口明确，本轮修正设计见下一节 |
| `v11-lateral`，原地方向辨认 | 可自然略开，辨清板长、板宽和身体正面；只做小幅支撑练习 | 已有独立开放参数；不需放大成高阶低位，也不能当完整滑行示范 |
| `v-mid-position-30`、`v18-neutral` | 找能双向调整的自然参考，允许肩髋随任务变化 | 不以与JSBA角度不同判错，也不要求强制闭肩 |
| `v-heel-open-progression`，五组练习 | 自然基准→只改朝向→回基准改时机→回基准改倾斜→恢复自然 | 保留单变量编排；第四组倾斜会使胸前水平投影略变，不等于作者额外转肩 |
| `v-toe-closed-drill`，前刃单弧 | 自然／略开放同进度比较，减少过量开向以恢复腿部活动 | 已有独立朝向对照；不是前刃一律闭肩，也不能替后刃作证 |
| 高低站位、反弓、一般换刃与回收基础课 | 允许舒适朝向，分别练高低、跨板、屈伸或两刃关系 | 不为“统一开放”再加一个变量；主线调用它们时说明其基础范围 |
| 普通浅刻滑 `rail-track` | 自然略开、两刃可调，先保窄痕与计划结束 | 当前已有一定自然开向，不自动复制高阶低位参数 |
| 普通搓雪、CASI4小回转与独立原型 | 以板控、可控滑移、完整弧和整段连续性为目标；上身可相对平顺、下肢更明显转动 | 可采用任务适合的开放/分离；上身少转不等于锁死或必然反拧 |
| `v24-heel-pivot`等诊断课 | 先有自然参考，再按最早变化查朝向、板角或前后位置 | 自然参考图不冒充已复现所有开肩病因；同一现象保留多因 |
| `v19-counter`、`v19-mixed` | 保留专项同时反向、解除分离及接回自然连弯的先后 | 不能用静态开放造型取代过程，也不是每个小回转的必修动作 |
| JSBA高阶低姿态八字 | 将明显开放、分腿、两刃与两向转换按个人条件组织 | 作为本站应用终点，不成为全站唯一自然位 |

“同向协调”说主要转弯段的总体组织，不要求整周期每一毫秒肩、髋、板的转动方向都完全相同；转折附近的自然相位差要按阶段判断。

## 4. 两门后刃课：原缺口与本轮修正设计

复核起点，两课共用`fore-aft / rear-heel / single-arc`。原阶段为两脚之间、小幅向后脚侧、观察双腿、回中；朝向输入只有板相对髋约2.865°、肩约5.157°，没有自然／较开放对照。转头看向行进方向不能代替开肩或开髋。

本轮设计保留稳定课程ID、原路线与前后微调用途，增加同进度的**自然朝向／胸与骨盆略多朝板头**对照：

1. 切换时保留路线、脚位、板角、进度和原前后微调编排，分别观察胸前短线、腰前标记及方向图。
2. 阶段0先辨认朝向；约15%看同朝向下的沿板长微调；约45%区分头、胸、骨盆与双腿；约68%回到两脚之间，同时保留所选朝向。
3. 两档只比较作者编排的朝向条件。身体实际关系仍可能随关节配合改变，不能把它包装成严格的人体因果实验。
4. 原刚体雪板不显示板尾局部扭转，也不计算真实两脚压力。需要排查局部刃角时，应转到已有扭板工具，而非把前后位置图改名当成后脚刃角图。

同时统一朝向的可观察表达：板头作参照，胸前与骨盆前方分别显示，头部可独立转动。这个观察方法可用于不同任务，**不等于把不同任务的动作参数统一**。

本轮已实现上述对照入口、专用阶段与共享朝向观察组件；源码存在本身不授予渲染、测试或教学通过，实际执行范围另列于下文。两处“自然横向站姿”的旧说法已改为以舒适自然朝向作参考，避免把自然误解成完全侧身。

最终两档保留同一路线、11°后刃、固定器、靴与小腿输入，只切换作者编排的胸髋开向。沿弧展示前后微调与回中，没有模拟建刃或下一刃转换。新档输入髋18°、胸32°，实体骨盆正面的水平开向随倾斜为约16.41–18°、胸前为32°；这些都是示例。816组两前脚同进度配对中，板状态、滑行方向、靴、踝和膝严格相同；固定骨长求解却使骨盆沿板长比自然档更靠板头约5.95–6.12厘米，独立视线限幅的结果也会变化。因此只称“同一前后微调编排”，不称全部实际身体位置或头部朝向相同。不能为压平派生位移去挪动固定脚位或改骨长。

五组练习第四组的准确表述可为：“保持肩线转向，身体倾斜变化会让胸前的水平投影略变。”独立数值审查在后刃峰测得约0.803°的派生变化，髋不变；没有证据要求为消除这点投影差而修改动作。
