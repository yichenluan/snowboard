## 反脚：方向改变，脚的身份和装备不交换

`switch.ts` 的 `switch-linked-skid` 从第一帧开始反脚，原后脚沿行进方向领先。`boots.front/rear`、固定器脚角、原板鼻和原板尾始终保持身份；regular/goofy只决定惯用前脚与世界镜像，`rideDirection=-1` 才表达原板尾领先。换刃后前刃仍是脚趾侧，后刃仍是脚跟侧。

原前脚与原后脚的装备角保持示例原值+18°/-9°。世界板轴yaw按反向行进组织，同时调整roll符号以匹配路线弯向；只在原正脚姿态上加π会把脚趾侧法向倒到路线另一侧。髋、肩和视线重新组织，头相对肩转约54.4°，实际视线对准新路线，不依靠头部限幅造成持续偏视。

作者路线为两个搓雪圆弯，横向宽度3.6m、一个周期坡下14m，刃角峰值14°、相对行进前端的滑移角0–8°。这些是可观察的运动学参数，不是速度、考核走廊或推荐姿态。100%仍在滑行，下一周期平移14m接续。平板附近采用调刃速度趋零的波形，避免雪面高度绝对值造成垂直速度折点。

公共输出兼容：`MotionState.rideDirection`可选，缺省为正脚语义；`metrics.skidAngle`相对当前行进前端计算，反脚用`-nose`，不误报约180°。三维骨架标注“原前膝/原后膝”；俯视硬件板鼻箭头保留身份。课内播放器已显示“惯用前脚”及“当前行进前脚：原后脚”，方向对照使用行进前端。三维板鼻标记已修正到板面可见高度，并完成画面复看。

## 扭板：连续局部板面与独立固定器框架

`twist.ts` 提供两任务：`progressive-twist`演示一次前段稍先、后段接续；`twist-timing-compare`在同一xz路线和yaw下比较`near-synchronous`与`front-earlier`。两向转换通过`fromEdge`独立选择。它们都是移动换刃，原地感知留在正文，不把滑行起点称作静态站姿。

`prototype/board-surface.ts` 描述可选`segmentRolls:{front,rear}`。每个固定器及完整鞋底足印位于局部roll恒定的区域，中间x∈[-.15,.15]m作连续五次插值。鞋底、固定器、踝点与胫骨使用各自局部法向；股骨、髋宽与躯干仍由共用定长约束求解。刚体默认不使用此扩展，保留原渲染和求解。

同源连续网格实际显示板前后截面不同roll，不只改变靴筒。板面作为整体抬高到几何最低点不穿雪，未把各截面独立移到雪上。由此另一段低侧会短暂高于平面雪，约9.2mm；1001帧网格采样峰值为9.17mm，精确局部平板事件处为9.183332mm，不能把网格采样值当作严格上限。这正是当前几何能力的边界，不能称为整条刃同时接触或压力计算。绿色线只标每段几何低侧，中央扭转段不画虚假的整刃接触。`TwistSectionDiagram`使用同一板面和靴底法向，显示两段角度和低侧高度，可在禁WebGL时继续阅读。

作者设置起止两段共同13°，最大前后角差约4.044°。提前版原前脚处实际平板事件为46.176%，原后脚处为53.824%；不是固定生理时差。82.5%后两段恢复同一新刃，末态不保留大扭转，也不表示停止。

最初直接取两段最大高度时，在中点交换最低点会形成垂直速度折点；修正只在独立任务的42%–58%调刃进度加入单调连接，中点调刃速度为零，路线与yaw继续行进。没有通过整板悬浮或分别移动截面掩盖接触问题。两靴跨过各自平板时使用平滑靴筒包络，避免前后脚不同零点又产生胫骨速度折点。

## 共享接口与课内接线

| 接口 | 当前实现和调用约束 |
| --- | --- |
| `PoseOptions.segmentRolls?: {front:number;rear:number}` | 弧度制，传给`buildPose`；局部板面、固定器、靴底与踝点同源。任务目前同时令`route.roll`为两段均值；不得将均值用于替代局部靴底法向 |
| `PoseOptions.rideDirection?: 1\|-1` | 缺省为正脚；反脚显式传`-1`，输出保留在`MotionState.rideDirection`，不交换`front/rear`身份 |
| `boardToWorld(local,board)` | 保留已有调用方式；有`segmentRolls`时按`local[0]`计算局部roll，无扩展时执行原刚体转换 |
| `boardVectorToWorldAt(local,board,x=0)` | 将方向而非点转到指定纵向位置的局部框架，不加位置平移 |
| `surfaceRollAt` / `surfaceSnowHeight` / `surfaceHalfWidthAt` / `surfaceMeshData` | 位于`prototype/board-surface.ts`。分别提供局部角、整板最低点贴雪的高度、圆弧轮廓半宽与实际变形网格；课内二维轮廓使用同一定义 |
| `sampleSwitchLesson(t,config,stance)` | `type="switch"`且`task="switch-linked-skid"`；`supportsSwitchLesson`用于任务门控 |
| `sampleTwistLesson(t,config,stance)` | `type="twist"`，任务为`progressive-twist`或`twist-timing-compare`；`fromEdge`选择起刃，`twistTiming`为`near-synchronous`或`front-earlier`；`supportsTwistLesson`用于门控 |
| `TwistFrame.segmentEdges` / `twistTiming` | 前后段分别报告解剖前刃、后刃或平板；不能将中央`state.edge`命名为全板工作刃 |
| `TwistSectionDiagram({state,stance})` | 360×220 SVG；在两个扭板入口的说明区常驻，包括平面模式与禁WebGL降级，避免依赖全身图读取约4°差异 |

`prototype/scene.tsx`按可选字段选择变形板，普通动作不需要新组件参数。`lesson-player/motion.ts`与`registry.json`已注册反脚及两个扭板任务，`LessonConfig.twistTiming`传入采样器；`content.json`三引用分别显式配置`switch-linked-skid`、`progressive-twist`和`twist-timing-compare`。两处扭板入口均可切换转换方向，对照任务另有前后段时序选择器；切换暂停播放并保留当前进度。正文与动画指南区分原地感知、移动换刃和独立停止，未把完整练习流程全部算作动画覆盖。

课内`PlanarDiagram`已使用实际底面轮廓：扭板的板宽投影画原前、后固定器位置的两条底面截面，沿用橙、蓝身份颜色；板长投影采样`surfaceHalfWidthAt`给出的两侧边界并经`boardToWorld`转换。刚体板也使用实际板底轮廓。每个投影均使用同一世界坐标骨架，雪面线由世界y=0代入当前投影，不另造姿态或固定雪线像素。

沿板鼻的板宽投影会使两截面互相遮叠，这是投影本身的限制；分栏的`TwistSectionDiagram`显示两段实际角度、靴底法向与低侧高度，不夸大扭转角。离雪低点画为空心点，落在几何雪面上的低点画为实心点。反脚的`DirectionComparison`已将鼻轴乘`state.rideDirection??1`，标为“行进前端（原板尾）”；俯视路线和硬件鼻尾仍保持原身份。路径诊断文字已改为“雪板端点的几何路径”，不声称这些轨迹是整刃接触或真实雪痕。

## 实际执行的数值检查

- 扭板：两向、两站姿、两时机各1001帧，共8008帧；反脚：两站姿各1001帧，共2002帧。
- 两类合计最大骨长误差1.33e-15m，固定脚位误差1.79e-15m。扭板实际渲染板面采样最低y=0；局部靴筒示例保持12–18°。
- 反脚全程原板鼻与行进方向点积小于-.98，原后脚在行进方向领先超过.5m；骨架左右镜像、完整周期接续和实际视线均核对。
- 检查真实前后段平板、时序连接边界和中点支撑转换的板与全部关节速度。h=1e-5时，中点板高速度差3.46e-8m/归一时间；全周期最大有限差分残差随h减半而减半，属于正常二阶项，不是保留的速度跳变。
- 在h=1e-5/5e-6/2e-5下，同一反脚采样点的最大关节速度差分别为.001548907/.000774454/.003097813m/归一时间；扭板同点分别为.000832709/.000416354/.001665418。中点扭板最大关节速度差2.01e-5，反脚两次平板附近约7.9e-5。差分是对当前函数的数值连续性检查，不是连续时间形式证明。
- 7项反脚与扭板独立测试覆盖刚体缺省等价、局部安装面、同路线时机对照、骨长/脚位/镜像/网格不穿雪、反脚身份和全关节连续性。公共接线完成后，主线程确认全套85项测试、严格TypeScript检查、课内播放器与独立原型两项构建通过。
- 独立审阅再按两向×两站姿×两时机各1001帧检查截面投影，共8008帧。由实际世界截面反算的角度与图示角度最大误差为2.78e-16rad；两段几何低侧最低为0，网格采样最高为9.1703mm。50%近同步两段均为0°，提前版两段分别约±2.02187°，两向与两站姿的解剖刃名一致。
