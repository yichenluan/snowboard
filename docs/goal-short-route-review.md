## 4. 更新后的主线闭环

**入口自测 → 两条可选桥梁 → 完整小回转 → 按问题纠错 → 可逆变化 → 情境复测。**

1. 先在当天熟悉容易坡检查双刃停止、中弯两侧出口和速度、双向渐进释放。走刃顺畅、高级道大弯和ollie自述不自动通过这些结果；反脚能力单独记录。
2. 换侧不从容：用 `s-short-sideslip`，先稳侧滑与单弯，再缩短等待。中弯已稳定：用 `s-short-size-ladder`，缩一级后随时放大回来。不是每人必须按顺序完成两条支路。
3. `s-short-integrated` 作为完整示范单元。先看路线，再看两向转换；每组4至6弯为建议量，末段主动放大并停止。伸展/屈曲可沿用已有方式，回收不作门槛。
4. 一侧不顺：`s-short-diagnosis` 先区分路线、释放、前后位置、肩部代偿或活动余量，再只选一个纠正练习。无证据时写“无法判断”，而非输出一个确定肌肉原因。
5. 完整小弯稳定后，分别练节奏、弯宽、出口和主动结束。撤口令并换一趟同条件重复；地形/雪况改变就回到容易中弯复测。
6. `v17-retract-drill` 与 `v13-down-drill` 保留为扩展工具；反脚是并行支路，不把正脚通过自动映射到反脚。

建议门槛关注路线、时序、速度、余量和可恢复性；没有“看过即掌握”“蹲得低即进阶”或固定频率成绩。不会自动替用户完成自查。
