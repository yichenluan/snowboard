# 转向、刻滑、小回转与诊断：逐结论来源复核

日期：2026-10-15。范围：rotation 13、carving 7、short-turns 7、diagnosis 6，共 33 课。本报告是文本来源审阅，不把它计为动画实拍标定、页面访问或个人雪上能力通过。

## 实际工作与证据边界

逐课阅读 mechanics、execution、prerequisites、checks、drill、mistakes 及所有 citations；对照官方手册的实际页文本和官方网页正文。S18 是例外：当时只读到官方域搜索返回的规则段，原页打开失败，不能称作网页全文实读。原逐结论账本共 714 条，含逐引用、原理、执行、每张诊断卡、前置、验收及各练习字段。原本已有的核心课组数没有统一改写，33 课新增 drill.dose，明确本站建议、组间复盘与质量停止。后续改用 S37、官方关键帧对照和第二轮文案修订以 [统一来源账](source-claim-audit.json) 的显式补核记录为准，原账保留审查历史。

- direct：所列来源直接支持该限定主张，不代表整课都出自该来源。
- synthesis：原始原理与具体情境的归纳；条件化诊断仍须现场或可辨识录像检验。
- suggestion：本站教学组织、剂量、机位、对照、退阶与自测门槛。
- unverified：本轮没有逐段看本地原视频，也没有把模型与真人逐帧校准；24 个旧时间线标记与33课实拍对应均保留未核验。

“直接支持”不能把教材的教练考核条件变成全体学习者的唯一规则；S10 不同等级的前后调节/屈伸任务不同，本次没有把某一任务列提炼为固定通用时序。S26 的观察方法也不能证明每种失稳的具体原因。

## 修复的关键问题

1. 开肩后腿僵、长弧后急弯、扫尾前肩先动等现象，原有若干 cause 过于确定。改为待验证解释，增加区分方法；尤其“长弧必然加速”改为检查出口、坡度与释放。
2. v-heel-open-loading 原引用 p157–158 与开肩承重不匹配，改用自然位、旋转、压力、两刃差异、装备的实际相关页。
3. CASI p74 J 弯是单脚初学滑行例，p86 回指该练习；本站双脚固定的刻滑单弧应主要引用 p97–98 独立横切/弧线，并标为教学改编。
4. S18 原 claim 将 starting downhill / look uphill 混成“朝上坡移动前观察”。改为起滑或进入雪道前向上坡观察；转向上坡前检查是本站路线建议。
5. v19-stable-upper 用两个高级专项支持普通小弯过于宽泛。新增 S10 p14 搓雪任务，T01 只说明 down-unweighting 与 counter-rotation 各有情境。
6. 诊断课程的 S10 Movement Analysis 细化为 p11–13，技术贡献另指 p4–5/14–15。S26 保留确实存在的章节，但只支持观察和反馈方法。

纠错记录：最初一次网页返回较短，曾误报 S26 缺少 THE POWER OF OBSERVATION AND POSITIVE REINFORCEMENT。完整重开网页并与官网正文缓存交叉读取后，确认该节及 one manageable cue 均存在；已撤回该误判，补丁没有删除真实章节。S10 也确实有 Movement Analysis 专章，最终定位为 p11–13，而非只凭泛标题。
