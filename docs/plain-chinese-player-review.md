## 关键改法

| 原表达 | 当前表达与含义 |
| --- | --- |
| 看两刃成角 | 看两刃姿态；实际比较内倾和反弓时，具体解释腿与上身倾斜幅度不同，以及踝、膝、髋怎样配合 |
| 胸廓相对回板 | 胸部相对骨盆更靠近雪板上方；保留相对位置含义，不承诺胸部始终位于雪板正上方 |
| 板轴、路线切向 | 雪板朝向、实际移动方向；保留搓雪时两者可以有夹角的区别 |
| 髋踝距离包络后移 | 屈伸动作整体延后，髋到脚踝的距离变化幅度和周期不变；没有把它改称放刃延迟 |
| 通道 | 滑行走廊／示意走廊，并解释它指连续转弯占用的横向宽度，不是单个弯的半径 |
| 同源平面、身体组织、世界肩线 | 与上方人物同步的平面图、身体配合、不把肩膀固定朝向雪道某一方向 |
| 靴底法向、几何低侧 | 垂直鞋底的方向线、该段较低的一侧板刃；继续说明图中离雪高度不能当作压力 |
| 基准动作／教学强调 | 常规显示／辅助观察；控件值、默认值与行为保留，说明辅助观察增加骨架与对照，不放大动作 |
| 主动回宽恢复、两维缩小 | 主动放大弯恢复、弯的宽度和下降距离一起缩小 |
| 结果能力、需补核前置 | 滑行能力、先核对基础；进度计算与学习关系不变 |

首页原有方向说明补充“立刃”和“刃角”的直白定义。反弓、回收、转板、屈伸、膝髋等专业词按语境保留，不把所有关节角度变化都称为反弓。英文正式任务名、机构名称、来源页码与链接保持原样。

原型页脚写死的“102 课”改为“全部课程”，避免课程数量变化后再次过时。

整合前追加一轮显示词核查：选择器改为“起始板刃”“斜滑板刃”“第一弯用哪条刃”；统一明确的“刃角”，并将“前刃探胸”写成“前刃上身先扑向雪面”。原型说明把当前板刃与脚尖／脚跟两侧对应说清。这轮未增长 SVG 图内文字。

## 技术含义核对

- 专家小回转的 `recoveryPhase` 只平移屈伸周期；专家刻滑的 `timingShift` 也只平移屈伸周期。已读对应公式，确认“幅度与周期不变”来自现有实现。三档屈伸时间比较另读 `pressure-advanced.ts` 的时间函数，确认开始时刻变化而幅度和持续时间不变。
- 保留前后刃不对称、双脚固定、骨长不变、软靴范围为示例、伸腿不自动减压、近平板不等于零压力、骨盆不等于质心、不计算真实压力或抓地等边界。
- 反脚继续保留原前后脚和原板头板尾的身份；扭板继续区分整板改变朝向和前后段刃角不同。
- “胸廓”改为图示位置更易理解的“胸部”，未把胸部位置等同于全身重心。
- 旧 SVG 伸展调压提示澄清为“身体仍在上升但逐渐减速时，脚下支撑力可短暂减小”，与现有原地屈伸讲解一致；没有改力学模型。
