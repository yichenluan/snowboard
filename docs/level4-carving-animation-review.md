# 低姿态八字刻滑：现有动画与可观察性审计

日期：2026-10-15。代码基线：`a2b0aca`。本次由 `inventory` 阅读现有规格、模型、播放器与测试，并做独立数值采样；**本报告没有新增浏览器或人工图审通过记录**。真人观察与本轮实际画面由根代理另记。未改课程、动作几何、共用人体或总审计账。

## 结论与最小方案

保留 `duck-carve / linked-duck-carve` 作为正常高度、适量降低与前刃探胸的身体关系比较。现模型已经包含两刃控制及两向转换，不需要为了增加 CASI 四级内容而先增加刃角、加快播放或套用专家小回转姿态。它不应改名为已经满足专家大回转条件的示范。

当前最重要的补齐是：课程把模型可见关系与官方任务、真人结果分开；实际图审覆盖周期内前换后及跨接缝后换前；练习记录不携带小回转专用通道提示，也不在不同协议间串用记录。只有真实画面或任务目标暴露具体缺口后，再考虑独立路线或动作。

| 可观察对象 | 当前实现 | 结论与边界 |
| --- | --- | --- |
| 正常／较低 | 同一路线、同一板角、同一时间；较低条件重新组织下肢与胸廓 | 可比较身体组织与活动余量。不是单独改变骨盆高度的实验，也不能证明相同速度下都力学平衡。 |
| 较低／探胸 | 保持板和下肢，前刃另增加胸廓前探；后刃与较低条件相同 | 可隔离前刃胸廓关系；不是两刃通用反例，也没有计算失刃后果。 |
| 双刃控制 | 前后刃采用不同屈曲与躯干包络 | 已有独立关系，不能按视觉对称性要求重做。 |
| 前换后 | 在周期中部完整经过前刃减角、近平板、新后刃 | 可在同一次播放内看完。 |
| 后换前 | 后刃释放在周期末，新前刃建立在下一周期初 | 需要跨 `1→0` 循环观察；单次播放停到100%并没有继续显示新前刃。 |
| 起滑进入 | `t=0` 已处于弧间近平板，仍在移动 | 不是从静止起滑、斜滑接弯或第一弧进入示范。 |
| 退出 | 有恢复余量与继续下一弧的文字；`moving`始终为true | 没有主动增加滑移、减速到停或到停止区的动作。暂停按钮不能代表雪上停止。 |

## 当前任务与变量

实物为 [carving.ts](../lesson-player/carving.ts)，唯一任务 `linked-duck-carve`，三种 `posture` 为 `normal / low / reach`。当前课程 `s-duck-low-linked` 使用 `low`，14秒作者观察时长，并开启板头／板尾路径诊断。

- 固定器使用 `+18° / −9°`、刚体板长1.58米、宽0.265米，均为作者设备设定，不是推荐参数。
- 路线由正弦方向函数积分，板轴对齐中心移动方向；板角为正弦包络，作者峰值26°。路线不由载荷、雪况、速度或侧切动力学算出。
- 前后刃额外屈曲分别由正、负半波平方驱动，幅度不相同。前后胫骨与两条股骨独立求解；双脚身份随Regular／Goofy切换保持。
- `normal→low`改变下肢和配套胸廓关系，不改变雪板；`low→reach`只在前刃增加胸廓俯仰，其肩、手、头会随躯干链变化，不能误写成只有胸点移动。
- 当前没有duck的起始刃切换，`fromEdge`不参与此任务。两方向存在，但不应向其配置中写一个被忽略的`fromEdge`，再声称起始方向可选。

## 本轮数值检查

独立脚本在两前脚方向、三姿态各取1,601点，共9,606个主样本，并逐样本比较正常／较低参考。执行 `tests/carving.test.ts`：4/4通过。原测试覆盖路线相同、脚位与骨长、阶段工作刃、接缝姿态、路线切向及身体相对板的速度连续性。

| 检查 | 本轮结果 | 不能推出 |
| --- | --- | --- |
| 三姿态板位置、板角与板朝向 | 差为0 | 同一速度和负荷下真实平衡成立 |
| 股骨／胫骨长度 | 最大误差约 `3.1×10⁻¹⁵ m` | 真实关节活动或全部表面无穿插 |

| 后半周期low／reach全部关节 | 差为0 | reach是后刃错误示范 |

| --- | --- | --- | --- | --- |
| 前刃 `t=.25` | 0.787米 | 0.688米 | 0.046米 | 0.112米 |

## 当前不能展示的关系

1. **真正的刻滑接触与雪痕。** 板轴与中心速度对齐是编排结果；板头板尾两线只是刚体端点路径。没有连续接触刃、真实雪痕、板侧切变形或板雪作用求解。
2. **前后段不同接刃时刻。** 此任务没有`segmentRolls`，整板只有一个roll。前后胫骨略有不同不等于前后板段依次接雪。正文可讲原理，但不能指着此模型说已经显示了前段先接、后段后接。
3. **压力、储能、回弹和动量。** `edgeLoad`只是`abs(wave)`编排字段；课内场景当前不以它画实测压力。没有质量、真实坡度、速度或接触材料模型，不能由高度、刃角、轨迹或手的接近雪面推算压力。
4. **姿态错误的后果。** reach与low的雪板完全相同，不能展示探胸造成的滑出、卡刃、路线失控或“同姿态也能成功”。正确用法是对照身体关系，再去真人／雪上检查结果。
5. **专家条件与适应。** 固定路线、固定板角包络、固定身体时序不能验证专家地形／速度或变化条件下的弧线选择；也不能把14秒播放换算成实际滑速。官方任务条件由本轮来源研究独立确认。
6. **退出、停止与完整任务验收。** 当前两弯闭环仍在向下移动。真实退出需要有意改变滑移与控速；模型只给文字，不已演示。

## 实际画面审阅的精确入口

实际工作刃阈值为`abs(roll)<.008 rad`。事件从此阈值求出，不用25%／75%替代转换。下表用归一化进度；14秒换算只用于播放器定位。

| 事件 | 归一化时点 | 14秒进度 | 建议观察 |
| --- | --- | --- | --- |
| 新前刃刚建立 | `0.002806`之后 | 约0.039秒 | 靴近景核连接；板头方向看膝髋开始换侧 |
| 前刃控制峰 | `.25` | 3.5秒 | normal／low同帧，再low／reach；板头方向与前后平衡视角 |
| 前刃减到近平板 | `.497194`之后 | 约6.961秒 | 不能只停在.5；应从.47连看至.53 |
| 新后刃刚建立 | `.502806`之后 | 约7.039秒 | 骨盆脚跟侧、胸廓关系、两腿与高背 |
| 后刃控制峰 | `.75` | 10.5秒 | normal／low；reach应与low相同，不寻找不存在的反例 |
| 后刃减到近平板 | `.997194`之后 | 约13.961秒 | 从.97连过1→0再到.03，比较两周期局部姿态和行进方向 |

阶段按钮准确目标还有 `.13/.32/.63/.82`，应实际点击全部9项，并分别观察两种前脚方向。建议转换密帧为 `.47/.49/.497194+1e-7/.5/.502806+1e-7/.51/.53`；跨周期为 `.97/.99/.997194+1e-7/1/0/.002806+1e-7/.01/.03`。重合帧用于接缝两侧核对，不宣称新增独立动作。

最低画面范围：实体和骨架；整体、板头方向、沿板长／前后平衡、靴近景；三姿态同帧；前后刃控制与两向转换；1倍运行、慢放、暂停、阶段循环和完整循环。离散样本、正常运行、人工连续审阅、真人对照仍须分别报告。

## 最小实现建议及优先级

- **先做任务分工，不改几何。** 高度关系继续引用当前任务；专家弧形、加载管理、变化与验收主要由有边界的正文、真人分析和逐趟证据承担。复用不应冒称模型已经满足官方专家任务。
- **如图审发现高度差不易读，再加同源诊断。** 现有`legLengthDiagram:true`能显示当前髋踝平均距离，但duck默认未开启，且没有normal／low双曲线。可复用诊断组件加正常/较低的同帧距离与曲线，保留米单位和非压力说明，不提高人体幅度。`reach`对照应显示同腿长并指向胸廓关系，不用相同腿长曲线重复暗示错误已解释。
- **若需要直接循环“后换前”窗口，再做最小播放入口。** 现阶段可用完整循环跨接缝审阅；不要把现有末段循环误当已经涵盖下一周期新前刃。后续若增加跨周期段循环，需要独立循环区间语义和测试，不能只新增一个标签。
- **不为演示真实压力而借用小回转曲线。** 专家小回转的腿长、节奏与2.5米通道不能复制到刻滑。若课程必须直接对照不同弧宽／出口或时序，应先确认任务变量和来源，再做独立task；这不是当前审计已批准的模型改动。
- **本轮实际需要的通用UI修复。** 训练记录原通道提示硬编码小回转2–3米，应允许协议覆盖并把默认提示改中性；记录和编辑按`id + protocolId`隔离，避免四级小回转证据被重新标成刻滑证据。该修复由本代理单独实现和测试，课程协议内容由根代理集成。

参考边界：[既有duck专项](goal-duck-route-review.md)、[教学研究](teaching-research.md)、[原型规则](prototype-review.md)。历史画面和发布记录不在本报告中刷新为本轮通过。

## 训练记录最小修复结果

按根代理后续授权，仅修改 [assessment.js](../assessment.js) 与 [assessment.test.ts](../tests/assessment.test.ts)：

- `protocol.fieldHints`可按既有字段键提供字符串占位提示；未配置时用中性默认提示，未知键不进入表单，非字符串回退，空字符串可清空提示。输入框与多行框都经过现有HTML转义。小回转的2–3米提示由其协议独立配置。
- `normalize`遇到显式不同`protocolId`时返回本协议空白记录，不能把另一个任务的证据重新标为当前任务。缺少该字段的旧草稿仍按原兼容逻辑读取，不修改原对象。
- 历史编辑和保存替换均按`id + protocolId`匹配；即使两个协议记录ID相同，也不会误选或覆盖另一条。另一协议原对象保留。
- 6/6专项测试通过，其中新增3项分别覆盖协议隔离、提示转义及真实挂载处理器的同ID编辑／保存冲突。表单测试使用小型DOM边界替身，不声称实际浏览器交互或布局通过；后者由根代理复验。

这项组件修复没有修改动作几何、正文或总账。
