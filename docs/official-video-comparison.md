# 官方实拍与本站动作的定性对照

2026-10-15，Chrome 中实际打开、播放并暂停 CASIACMS 官方视频，再用播放器逐帧键定位以下画面。先前 YouTube 登录阻塞是历史事实，本轮已正常看到画面。这里记录的是有限关键帧时序观察，既不是观看全部帧，也不是机位、速度、人体尺寸或受力标定。未下载或转载完整视频。

## 搓雪小回转

来源：[Level 2 Instructor: Riding Standards (2023)](https://www.youtube.com/watch?v=VSNG8OeHkjo&t=110s)，CASIACMS，片长约3:29。与 CASI Level 2 Course Guide 的 Short Radius Sliding Turns 任务共同使用。

| 实际观察时刻 | 可见关系 | 可用于本站核对的范围 |
| --- | --- | --- |
| 1:50.617 | 弯内双膝屈曲，板偏横坡，身后有明显滑移雪带 | 小回转可包含滑移，不等于纯刃滑 |
| 1:51.117 | 身体更低，板转到另一横向，局部被雪雾遮挡 | 不能从一个低姿态推断即时压力大小 |
| 1:51.617 | 双腿相对伸长、躯干较高，身体跨向板另一侧 | 支持本站温和伸展过渡作为一种可用示例 |
| 1:52.117、1:52.617 | 进入下一弧并倾向弯内，后一个位置再次屈曲 | 转换接上下一弧；板局部位于画面边缘，不据此测刃角 |
| 1:53.617、1:54.117 | 较高过渡后再次降低、板转横 | 观察两向连续变化，不能把弯中定格当完整技术 |

本站 `s-short-integrated`、默认 `short-turns` 和独立 `correct` 都表达“弧内调节—释放—接上新刃”，与以上可见的相对腿长和连续换向关系无明显冲突。本站的路线宽度、时间比例、骨段尺寸、关节角度与滑移角属于作者编排，没有由这段视频反求。视频不是“每次换刃必须伸腿”的证据；屈曲与回收分支仍依相应教材及适用任务解释。

## 刻滑与低姿态

来源：[Carving Instructor: Riding Standards (2025)](https://www.youtube.com/watch?v=zaQubyopOy8&t=28s)，CASIACMS，片长约2:46；视频由 [CASI Carving Instructor 官方课程页](https://casi-acms.com/courses/carving-instructor/)嵌入。

| 实际观察时刻 | 可见关系 | 可用于本站核对的范围 |
| --- | --- | --- |
| 0:28.848 | 后刃侧低位，膝髋折叠，胸廓相对骨盆回向板 | 两刃关系不能仅以同一身体姿势镜像 |
| 0:29.348 | 身体较高，腿相对伸长，向另一侧转换 | 低位弧之间仍需恢复调整余量 |
| 0:29.848 | 前刃侧低位，一只手触雪，整体向弯内倾斜 | 这是示范者的风格表现，不能变成必须触雪的要求 |
| 0:30.348 | 仍在低位弧中，手已离开雪面 | 触雪不是维持刻滑的必要条件 |
| 0:30.848 | 身体再次升高，手离雪，腿长增加 | 核对本站低位—释放—下一弧的完整过程 |

本站 `s-duck-low-linked` 的前刃膝髋共同移入、后刃膝髋折叠与胸廓回板，以及弯间保留屈伸余量，与这些画面的定性关系可比。视频机位不能读出固定器角度，**不确认该滑手采用本站的 duck 设置，更不作为 +18°/−9° 等具体角度的依据**。本课 duck 定义和装备条件来自厂家与教材；实拍仅用来对照软靴刻滑可见过程。模型低位幅度较保守，未追求复刻手触雪。

## 已排除的假证据与保留边界

定位过快时浏览器曾显示加载标志或旧帧；这些画面不计入上述记录。表中时刻均在视频已解码后重新读取并实际查看。时间的小数只用于重现播放器位置，不表示测量精度。字幕仅帮助定位，动作判断来自画面。

两条路线的实拍对照取得进展；其余课程没有因此自动获得逐课实拍核验。雪雾、相机跟随和裁边仍限制板雪接触判断；不宣称验证了足底压力、真实质心、材料变形或每个实体表面无穿插。
