# 专家短弯任务动画规格

本规格对应 `expert-short-turns`，是独立教学示意，不是CASI评审结果或实测动作重建。

## 依据与任务

[CASI Level 4 Riding Module（2025年9月）](https://members.casi-acms.com/documents/Riding_LV4_EN.pdf) 第5–8页将Expert Short Radius列为独立任务：2–3米通道、专家整备坡、advanced/expert speeds，通过弯形与引导控速、管理压力及回弹反应，并全程保持核心与高级能力。它与8米Corridor Run不同。官方未规定本模型的腿长、刃角、关节角或一种固定回收方式。

新模块有两任务，四配置。课内选择器保留当前进度，任意时刻可切回参考。

| task | variant | 公开名称 |
|---|---|---|
| expert-corridor-steering | progressive | 持续引导参考 |
| expert-corridor-steering | late-steer | 对照：改向较晚集中 |
| expert-load-release | continuous | 连续调节参考 |
| expert-load-release | held-release | 对照：屈腿准备偏晚 |

第一组在同一2.5米可见通道内，改变方向变化在弯中的分配；板中心路径、切向、板轴联动，路线曲率会变化，不能称严格同线路单变量。第二组保持相同板路线、板角、调刃时刻、脚位和靴筒输入，只后移实际髋踝距离包络，躯干随必要屈曲组织。它没有延迟实际放刃，不把可见屈伸叫作真实压力。

## 实现边界

- 新路线使用4次控制段到控制段转换，含连续近平板及新刃建立；起末仍在滑行。末帧不是停车，雪上安全退出由课程另行说明。
- 两种起始工作刃、左右惯用前脚均可选择；前刃与后刃分别组织膝髋和胸廓，不能只翻转人物。
- 图中2.5米是官方任务范围内选取的示意通道，默认16秒为观察用时；角度、腿长、弯深和时间均为作者编排，不能换算为专家滑行速度。
- 路线、人物、板头板尾路径及平面回退使用同一MotionState；新增三维通道线和俯视边界对应同一世界宽度。
- 腿长时机任务默认显示两条同源髋踝距离曲线，实线为所选动作、虚线为对照；两枚当前点和数值由各自同帧骨架计算。放大纵轴提高时差可见性，不放大身体动作，也不改成压力图。
- 继续使用真实固定脚、骨长及有限靴筒；共享人体/板求解与旧小回转输出不变。
- 没有压力曲线、板材储能/回弹、抓地失效、硬雪/雪堆或速度调控模拟；同线路不证明同真实动力学结果。上身有适量顺应，不锁世界肩线。

## 验收要求

测试检查合法组合、两刃/两惯用脚全周期几何、固定骨长与靴板连接、板雪几何、通道包络、实际路线导数、工作刃/滑移关系、单变量对照不变量、真实腿长时差、阶段事件、起末接续及接缝导数收敛。

实际页面还需检查4配置的正常播放、慢放、多视角、阶段入口/中点/末态、保持进度切换与回退。数值通过仅代表已检查的几何和接口，没有自动升级为教学正确或CASI L4通过。完整画面观察和来源对照由本轮独立证据登记。
