# Expert Short Radius 新增内容的逐项来源复核

日期：2026-10-15。审阅者：`duck_route`。本记录为新增六课、三课路线衔接和一份训练记录协议的人工来源判断。最终文字逐字段与内容哈希保存于 [source-claim-audit.json](source-claim-audit.json)，不以自动重算哈希代替复核。

## 已实际读到的证据

- **S38**：官方 September 2025 Riding 指南，第 3 页准备与反馈、第 5 页评分、第 6 页总体和小回转、第 7 页不同任务、第 8 页动作变化、第 15 页版本；其中第 1、5、6、8、15 页另作完整版面检查。
- **S16**：本轮重新公开下载的 Reference Guide 与原 2021 文件哈希相同，实际读第 43–59 页以及第 119–121 页；第 58 页另作完整版面检查。本文用于新课的精确定位集中在第 43–59 页。
- **S40**：现行四级课程页的 Riding 准备与外部反馈部分已实际打开读取。
- **S41**：2026–27 官方更新的课程框架与新评估网格两节已实际打开读取，只支持版本背景，不凭此给课文添加未出现的评估要求。
- **S39**：根代理实际观察两段官方短弯，共 15 帧。本审阅者读取独立的[观察记录](level4-short-video-observation.md)，核对新课是否超出该记录；没有声称自己再次观看原视频。可见关系来自该独立记录，压力、几何、时间和完整考试表现不因此获得标定。

下载、页码、方法、版本界限与本地文件摘要见[官方标准研究](level4-short-official-standards.md)。S38 支持任务，S16 支持技术关系，S39 支持有限可见现象；三个证据层次不能互相替代。

每课的目标、前置、检查、练习场地、准备、步骤、成功条件、停止、进阶与剂量均已连贯阅读。它们记录本站课程设计与保守质量边界，统一按 `suggestion` 保存；不因为同课引用官方教材而升级为官方处方。诊断条目整体按 `synthesis` 保存，原因保留不确定性，修正和区分程序为建议。示范配置是作者参数，来源账不认证完整动画周期或受力求解。

## 顶层验收协议的人工复核

`assessmentProtocols` 的 `casi-l4-short` 是本站训练记录工具，整体归为 `suggestion`。以下十一项的原始依据及解释已经逐项核对；完整协议对象另存哈希，不能只更新 lesson 哈希让协议变化逃过检查。

| 观察维度 | 已读依据 | 解释边界 |
|---|---|---|
| `task_conditions` | S38 p.6 | 2–3 米是走廊宽度；地形和速度无虚构角度、km/h |
| `centred_mobile` | S38 p.6；S16 p.43–45、57 | 动态平衡与余量，不要求专家全周期固定 50/50 |
| `lower_body_turning` | S38 p.6；S16 p.47–48、57、59 | 下肢配合不等于上身绝对冻结 |
| `working_edge_balance` | S38 p.6；S16 p.49–50、57 | 可支撑也可释放；失刃症状不能独断原因 |
| `strength_flow` | S38 p.6；S16 p.58 | 强而可动，不以锁腿或最低姿态验收 |
| `arc_to_arc` | S38 p.6；S16 p.58 | 弧线接续，不强制纯刻滑或平板停顿 |
| `loading_deflection` | S38 p.6；S16 p.51–54、58 | 管理响应；录像不直接测压力或弹性能 |
| `steering_versatility` | S38 p.6；S16 p.58–59 | 配比可选择，不宣称一种关节模式通用 |
| `shape_speed_control` | S38 p.6 | 控速依赖弯形和转向；本站不制造速度数值 |
| `run_consistency` | S38 p.6 | 全程能力；未观察或被遮挡应保留未知 |
| `variation_transfer` | S38 p.6、8 | 有目的变化与迁移；一次一项是本站建议，正式小回转仍在专家压雪地形 |

三种记录状态和证据文本的作用是区分未观察、仍需发展和当前条件可重复。记录结果不映射 6/10，不映射官方“通过”。合格外部反馈单独记录；没有反馈时明确保留待复核。

## 旧课衔接与保留

- `s-short-integrated`、`v17-retract-drill` 只增加关联课程，保留旧课地形与技术要求；新增关联按本站导航建议记录。
- `s-short-adapt` 增加专家路线关联，并在 `drill.progression` 末尾说明熟悉缓坡复测不自动等同专家条件任务；原有进阶文字和人工记录保留，新句由 S38 p.6 与本站分流设计支持。
- 三份原始人工账不改写。旧课受影响结论保留原 provenance，另加入本次补核记录；新增六课独立保存全部字段绑定。

本次没有消除历史 57 项视频时间线／真人标定缺口，也没有给新六课自动添加“真人标定通过”。只有复核课因独立的本课视频观察记录获得 `limited_keyframes`；引用相同视频的其他页面不能继承这个状态。
