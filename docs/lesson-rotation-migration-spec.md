## 最小能力与验收

旋转从实际肩线、髋线和板轴的连续世界朝向验证。相对夹角增加不等于反向旋转；反向活动区间需要肩/髋角速度异号、髋/板同向。混合示例只反向一次，之后恢复协调。手臂舒适目标可用现有手部IK，保留肘余量。

扭板不能仅改变两个cuffPitch。当前board.roll统一，鞋底/法向/固定器/踝点皆刚体。最低方案：可选frontRoll/rearRoll、连续局部板面、各固定器和靴踝跟随对应局部板架，再用现有双腿约束求骨盆。默认两roll等于原值以隔离其余课。两端异刃时需局部状态提示，检查穿雪，不宣称整条刃接触求解。

反脚需独立rideDirection，保留原前后脚身份、角度、颜色和原板鼻尾。反脚移动时nose·travel<0；滑移角要相对行进前端（-nose），否则会误报180°。板yaw加π后重新核对roll与世界弯向；肩髋和视线为朝原板尾行进重新组织，不能靠颈限幅硬凑。UI区分惯用前脚与当前行进前脚，两站姿都测。

## 待修文案

- mixed预设与清单统一“后刃调速后恢复自然连弯”，修“自然自然姿态”。
- 后刃诊断focus明确可控基线和未复现全部症状。
- 两个arms-feedback引用分task，横切与圆弯不合并。
- 朝向对照不把同一作者路线当成某个肩角改善抓地的证据；姿态不等于后脚压力比例。
- 通用朝向来源用CASI43/45/47–48/59；157–158的特定解剖讨论不能充当所有肩角任务的标准。
