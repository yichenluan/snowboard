## 最小能力与验收

旋转从实际肩线、髋线和板轴的连续世界朝向验证。相对夹角增加不等于反向旋转；反向活动区间需要肩/髋角速度异号、髋/板同向。混合示例只反向一次，之后恢复协调。手臂舒适目标可用现有手部IK，保留肘余量。

扭板不能仅改变两个cuffPitch。迁移前的board.roll只有整板刚体角；现已通过可选`segmentRolls:{front,rear}`实现连续局部板面，各固定器、靴底、踝点与胫骨共用对应局部框架，再用双腿约束求骨盆。缺省配置保留原刚体行为。两端异刃时分别显示局部状态和低侧离雪高度，检查几何不穿雪，不宣称整条刃接触求解；实现与实际审阅见[反脚与扭板研究](lesson-switch-twist-research.md)。

反脚现使用独立`rideDirection=-1`，保留原前后脚身份、角度、颜色和原板鼻尾。反脚移动时nose·travel<0；滑移角要相对行进前端（-nose），否则会误报180°。板yaw加π后重新核对roll与世界弯向；肩髋和视线为朝原板尾行进重新组织，不能靠颈限幅硬凑。UI区分惯用前脚与当前行进前脚，两站姿都测。

## 第八批正文与配置修订（2026-10-14）

- mixed 明确为“后刃调速后恢复自然连弯”：先在同一后刃上恢复自然肩髋关系，再减旧刃、过平板接前刃和后刃；修复“自然自然姿态”。
- 五组朝向课改为自然基线、只改朝向、只改屈伸时机、只改身体倾斜、回自然基线。每次先恢复其他变量，修正旧文案将各项累加的矛盾。
- 后刃诊断 focus 与动画标题明确为可控基线，不声称复现全部甩尾症状。真实诊断的正文保留，不把观察到的姿态换算成后脚压力。
- 两个 arms-feedback 引用显式分 task，横切观察与圆弯复测分别编排；圆弯课展示可控基线，没有制造抢肩反例。
- 前刃单弯增加 natural / slightly-open 配置。两档路线、脚位、板角与时长相同，只比较身体组织，不把相同的作者路线当成肩角改善抓地的证据，也不声称演出前后脚压力或局部扭板。
- 通用朝向引用改为直接相关的 CASI p43、45、47–48、59；朝向/时机/倾斜课另用 p49–57。移除将 p157–158 的特定讨论当所有肩角任务标准的笼统定位。
- 移除12引用的旧 demo.steps；运行阶段由 `rotation.ts` 同源给出。9任务的具体角度、幅度、时长和恢复先后是作者编排，不是机构统一动作处方。

### 资料直接支持与本课编排

本次又从本地 CASI 原始 PDF 读取 p43、45、47、48、50、59 的正文：自然站姿需保持活动能力，固定器设置影响自然朝向；上身与下肢旋转要区别，反向旋转要求同时朝相反方向运动；成角、倾斜与转向要服从任务。这些资料不提供本动画的具体肩角、刃角或秒数，也不证明所有姿态都适用于每个滑手。

9任务使用共享的固定脚位、靴与骨长求解，路线、肩髋世界朝向、动作分段分别编排。肩线在躯干平面投影后再求输入角，使画面中的实际肩线对应作者设定的世界朝向；不能只检查一个输入角变量。两档前刃对照保持板、脚位与路线相同，实际肩线相差8°，该差值是示例选择，不是教学目标。

### 已实际执行的几何检查

- 已运行8项独立回归检查、严格 TypeScript 与差异检查。覆盖任务门控、固定装备/骨长/镜像、同向/反向实际朝向、混合段拼接、停止末态、转头观察与对照保真；这些检查不等于画面或真实滑行动作通过。
- 重新采样11个展示配置、两种站姿，每种1001点，共22,022帧。骨长最大误差为 `1.14e-14 m`；镜像、固定脚位、几何低刃接雪误差为0。双膝几何屈曲为37.24–51.23°；实际胫骨相对各自鞋底法线在本例12–18°范围，手臂距完全伸直至少10.60cm。这些范围仅描述模型输出。
- 停止状态先前仅把弯中姿态停住，估计质心的雪面法向投影偏工作刃4.1–5.3cm。现停止最后20%单独安排腿部与躯干，保留6°工作刃，以分段质量估计的质心投影求末态支撑关系；最终横向残差小于 `1e-13 m`，纵向仍在板长内。前刃保留膝髋共同进入脚尖侧、胸廓相对更直立，后刃保留膝髋折叠与胸廓回板。6°及对应腿部参数是作者编排；这一简化投影检查不能证明真实坡度、重力方向和雪况下静态可保持。
- 混合段在36%和46%使用继承目标角速度的 Hermite 拼接。额外检查发现，只让 roll 连续仍会在过平板时因刚体板中心高度包含 `abs(sin roll)` 产生整人速度折点；现减小近平板区的 roll 导数，并对路线作连续积分。36%、46%、73%处，使用归一化时间步长 `1e-6` 检查板和全部关节，左右有限差分速度之差均小于 `1e-4`。这是归一化时间上的数值连续性检查，不是实测米/秒。
- 同向段以实际肩线、髋线与板轴验证，主要段总体同向，允许换向极值附近的自然相位差。反向活动段肩髋角速度异号、髋板同号；恢复段先板髋后肩，避免再次同时反拧。专项反向动作只出现一次；连弯末态与停止末态分开。

### 保留边界

教练实拍逐帧标定、真实靴材料活动、精细实体穿插、足底压力和板雪动力学仍未完成。静态停止的简化质心投影不替代坡度与雪况下的平衡验证；相同作者路线也不证明某个朝向更有效。数值检查与本批画面审阅只支持这12引用的实现记录；全站完成结论来自全部批次的独立记录与发布核验，见[项目状态](project-status.md)。
