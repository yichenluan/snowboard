# 安全规范来源补核

2026-10-15，NSAA `/nsaa/safety/` 在真实 Chrome 中返回 Site Maintenance，不能把搜索索引当作本轮成功打开原页。官方域索引列出的起滑观察要求在第4条；基础课草稿曾误记第5条，已修正。

为让两课有本轮实际可读的一手依据，`v-arms-feedback`、`v15-gaze-drill` 改用 [CWSAA Alpine Responsibility Code](https://cwsaa.org/safety-risk-awareness/alpine-responsibility-code/)（S37）的现行正文第4条。实际读取该机构页面的十条规范，起滑或进入雪道前观察上坡并避让；页面另嵌的2010视频明确是旧版本，未用其替代现行正文。只引用该具体原则，不把扫描训练、转头幅度或次数写成官方规范。

S18保留供其他既有引用回溯；本轮NSAA网页实时不可达不等于该原则没有证据。两课原来源账中的unverified记录保留在审计历史，最终引用有上述原文支持；不据此提升真人示范或整课教学认证。

二次核对审阅方法后，确认 `v20-traffic` 原账实际看到的是NSAA官方域搜索返回的第1–4条段落，`web.open`原页失败；并非原页全文读取。该课也改用S37本轮实际读取的第1–4条，分别支持控速、避让、停车位置和起滑观察。原账中的“官方页面检索完整规则段实际读取”保留为历史记录并在统一审计中显式澄清，不能计为成功读取网页正文。与弯形、横向占用和训练次数相关的建议仍是本站归纳。
