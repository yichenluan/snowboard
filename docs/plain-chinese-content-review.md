# 全站中文教学表达复核

日期：2026-10-15。起点：`2912a04`。本轮针对用户反馈的“前刃成角”“腿调角”等难懂表达，完整审读113课及目录、路线、能力图、术语表、复盘说明和播放器文案；保留原课程结构、练习细节与来源边界。

## 表达规则

1. 标题和口令先写动作：哪个部位、向哪里、什么时候动、观察什么结果。不能把“调角”换成另一个没有解释的缩写。
2. 常用专业词保留，并给出中文解释。反弓、立刃、刃角、放刃、引身减压、屈身减压、回收换刃、轴转与扭板分别说明；术语表保留原名称和英文以便查找。没有调查中文圈使用频率，不能声称某一种翻译是全行业唯一标准。
3. 区分三个角度：雪板与雪面的刃角、身体整体内倾、身体各段之间的角度。身体蹲得更低，不自动意味着刃角更大或压力更大。
4. 前刃、后刃分别解释：前刃看膝髋共同向脚尖侧移动和上身的配合；后刃看屈膝屈髋、臀部向脚跟侧与上身位置的平衡。不把反弓写成塌腰，也不把后刃动作写成坐向后脚。
5. 原理、练法、动作提示、真实测量和官方标准各自保留边界。技术词解释变通俗，不增加压力读数、固定关节角、统一前后脚比例或通用换刃姿态。

## 关键改法

| 原表达 | 现在的处理 |
| --- | --- |
| 前刃成角、后刃成角 | 课程使用“反弓”并直接说明膝髋与上身怎样配合；术语表解释原“成角”所指关系 |
| 腿调角、主动调角 | 按上下文写“用踝、膝、髋配合增减刃角”，或具体写立刃、放刃；不一律等同于屈膝 |
| 胸廓回板 | 说明胸部相对臀部更靠近雪板上方，保留具体参照；不要求上身始终竖直 |
| 板轴、枢转 | 日常用“雪板朝向”“主动转板”；术语表保留“板轴”“轴转 / Pivot / 枢转” |
| 腿长、髋踝距离包络 | 解释为髋到脚踝的距离，用来观察腿收起或伸出的程度；不是骨长变化，也不是压力曲线 |
| 通道、走廊 | 用“滑行走廊”，说明连续转弯占用的横向宽度；官方2–3米及7–15米不是弯半径 |
| 加载、承压、释放 | 按上下文解释弯中接住受力、用屈伸调节、配合放刃接下一弯；避免误读成猛踩板 |
| 基线、参考位、起中末、出口携带动量 | 展开为原来的滑行／参考动作、自然站姿、滑段开始中间结束、控制出弯方向并顺畅衔接 |
