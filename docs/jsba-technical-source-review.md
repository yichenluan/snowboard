## 证据方法与等级

- **direct**：一手原文明示的任务名、评价维度、版本安排或个人自述。个人原文的 direct 仍然只代表本人观点；不转成 JSBA 总会规定。
- **synthesis**：把官方目标、个人技术视角、有限真人画面与基本几何/力学组合的教学解释。分解腿部、靴—固定器—板的支持关系、身体跨板和阶段因果均按此处理，不反算真实压力、关节角度、板储能或肌肉比例。
- **suggestion**：本站的先后顺序、具体步骤、口令、练习剂量、前置、观察点、排错和退阶。引用资料提供背景，不使这些字段成为官方练习处方。

逐字段表使用零基索引。`mechanics[i]`覆盖该对象的标题、正文与来源声明，`execution[i]`覆盖标题、正文、口令、观察结果与来源声明；`mistakes[i]`覆盖现象、可能原因、修正、复核与区分条件。字段指纹为该字段 JSON 按键排序、紧凑序列化后 UTF-8 的 SHA-256 前 16 位，作用是让后续变更可使旧审读失效。指纹不是教学正确性的证明。
