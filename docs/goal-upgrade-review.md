## 更新后的学习路径

两条主线共享：双刃控速与停止 → 受控搓雪连弯 → 弯形控速 → 双向渐进释放。用户自述的正脚走刃、高级道大弯和ollie不自动勾选能力；反脚独立记录，可并行发展。

**搓雪小回转：**当天容易坡自测 → 侧滑接单弯或中弯逐级缩小（按薄弱项选）→ [完整连续小回转](https://jinke.me/snowboard/#lesson=s-short-integrated) → [先看路线再区分原因](https://jinke.me/snowboard/#lesson=s-short-diagnosis) → 可逆地改变宽度、节奏、出口并主动结束。保留温和伸展/屈曲示例，回收不是通关条件；4至6弯等练习量明确为本站建议。

**低姿态八字刻滑：**双侧可控窄痕单弧 → 正常高度浅弧连刃 → 可调整弯形与退出 → 两刃正常—较低—正常对照 → [低姿态连续与恢复](https://jinke.me/snowboard/#lesson=s-duck-low-linked)。失去窄痕、出口或活动余量就回正常高度；失败按单弧、释放、弯形或装备适配分流。不以够低、摸雪或静态照片达标。

基准/教学强调共享同一时刻、身体与板路径。强调增加骨架、平面图和适用的同步参考，不放大身体角度。duck可比较正常/较低/前刃探胸；默认伸展小回转可对照末段急甩尾。滑移本身不是错误，反例不是所有扫尾原因的诊断器。
