## 明确的验收矩阵

这是执行要求，下面均未授予本轮人工通过。当前核心基线有22个可见组合：专家短弯4变体×2起始刃×2前脚=16；duck3姿态×2前脚=6。共390个阶段按钮入口（16×21＋6×9）。这些数字是覆盖索引，不是要求以390张截图代替连续观看。新增任务按其能力门控扩展，不能为不支持的选项造组合。

| 维度 | 每个新task/允许variant的最低覆盖 | 必须观察/验证 | 失败或证据边界 |
| --- | --- | --- | --- |
| 两前脚 | Regular、Goofy各自完整周期 | 脚与装备身份、方向标签、轨迹及躯干不是镜头翻转；相机复位可用 | 一种前脚通过不能继承另一种 |
| 双刃弧线 | 每侧建刃、控制峰、出口 | 前刃膝髋跟随；后刃膝髋折叠和胸廓相对回板；窄痕目标与实际板轴/行进方向一致 | 峰值不能替代两段转换；不强行两侧外形镜像 |
| 两向事件 | 每次旧刃→近平板→新刃的准确事件、邻帧 | 从实际roll/edge和任务边界求时刻；在两种前脚分别核对字幕及状态 | 不用固定25/50/75%替代事件；近平板不叫零压力 |
| 阶段按钮 | 全部实际at及末态 | 点击后时间、stage索引、工作刃、字幕同帧；中点/末态补查 | 只对整数百分比采样会漏窄事件 |
| 正常播放 | 速度显式选1，完整范围到末态并再跨一次周期接缝 | 正常节奏、突然转头/跳姿、脚板连接、坡下移动与相机跟随 | 运行过与人工持续观看分开登记，不声称看过所有帧 |
| 慢放 | 速度0.35，重点两向转换及对照差异 | 身体先后、刃角、路径与曲线同步，时差有可见理由 | 通过数值差异不等于用户看得清 |
| 末态/重播 | End到100%，无循环重播；完整循环；末态分段循环 | 三种情况下均能继续推进；循环label对应非零范围；暂停生效 | 周期回跳标教学重播，不能说雪上倒滑/停车 |
| 多视角实体 | follow、front、side、boots；每侧控制峰和两向事件 | 整体支撑关系、前后位置、两刃成角、靴/固定器/高背连接和穿插 | 不挑一个角度掩盖问题；未知精细接触保留 |
| 骨架/同帧对照 | 透视关节与平面骨架；相同t切每个允许variant | 关节和实体吻合，目标变量实际不同，不变变量可核对 | 对照同时变路线时须明示，不能称严格同线路单变量 |
| 路线诊断 | 3D路线/2D路线/板轴/移动方向；showRoute开关 | 同源通道及图幅；完整板外廓而非板中心在声明走廊内；端点线仅几何路径 | 无接触求解不能标实测雪痕；场景边界与图上边界不得漂移 |
| 腿长/时序图 | 所有启用图的变体在控制与转换同帧 | 曲线来自sample输出；数值、圆点、选中变体一致，纵轴放大说明可见 | 不画伪压力、真实回弹或肌肉比例 |
| whole-run | 若新增任务宣称整段：入口、中段、末段和计划退出分别有真实输出 | 单条件变化后继续组织两侧，恢复基线或明确退出；有限任务末态状态真实 | 一个循环重复数次不等于新整段能力；未模拟条件不能说已适应 |
| 禁WebGL | 初始化前拒绝WebGL，在两前脚至少入口/转换/末态及重播 | 可读骨架、字幕、路线、同源诊断和控件可用；0canvas不能算3D渲染 | 无实体无法检查靴精细接触，结果单独记fallback |
| 页面与旧入口 | 所有新增引用逐课挂载；保留旧代表任务 | 标题/说明/variant/诊断按课生效；旧duck、旧小回转伸展/回收、原型代表可用 | 一个共享组件成功不能批量填其他引用 |

工程层另外逐配置检查：固定脚位、骨长、有限数值、工作刃/路线切向关系、预期零滑移或受控滑移、相对板/下坡平移的接缝连续、事件顺序、全部UI可选组合均可采样。导数连续用多步长左右差分收敛，不能以邻帧位移小作为唯一证明。真实靴活动范围、受力和雪上能力没有因此通过。

## 建议补缺顺序

1. **专家刻滑优先补一个真实独立任务。** 同源通道、路线切向、工作刃和出口，能看见落线前建立与连续刻滑的几何关系；允许以另一任务/变体研究腿长组织与恢复，但不得声称刚体模型验证加载和回弹。先保证已有duck基线仍可回看。
2. **专家短弯优先补整段组织或具体缺失关系。** 保留已存在的引导分配与腿长时机两任务，不仅提高频率、放大刃角或换标题。若新任务包含出口，则明确何时离开专家短弯条件、采用何种已有控速方式；不要将主动退出当成任务段仍然合格。
3. **低位应用与官方条件分栏。** normal/low/reach可继续作为有限姿态对照。若新增正常—降低—恢复的连续组织，用同源时序表达；不靠切换下拉框后瞬时跳姿当作雪上转换过程。
4. **压力与设备条件保留边界。** 不新增假压力曲线、材料弹性或硬雪响应。可以显示实际身体/板几何及官方实拍的有限对应，未模拟的关系交给原片和雪上证据。

新增`corridorSections {width,start,end,label}`用于有限序列的分段世界参照。三维与二维读相同列表；宽度不能随当前板位置移动，标签说明作者参数与官方任务区间。必须按当前板外廓跨区段的真实位置检查边界，不能只用板中心属于某段就忽略板头/板尾越界。相邻宽度改变应有明确过渡空间，不能突然缩窄后掩盖越界。

新增有限序列不要求末态与起点姿态相同；应检查内部区段连续、末态物理语义和播放重启。只有明确宣称周期动作的任务才要求扣除坡下平移后的首末姿态/切向/腿长及左右导数连续。将两种任务的循环验收混用，会把正确有限序列误判为接缝错误，或把不连续循环误当自然滑行。

新增刻滑5变体按两起始刃×两前脚形成20个基础组合；短弯planned-recovery与两种策略共3变体形成12个组合，新增共32个组合。阶段目标在模型冻结后重新采样，不沿用本文旧任务的时间数字。

## 证据回填和失效规则

基线逐条保存139个引用配置、输入SHA、页面/渲染/教学旧观察及其范围。后续新增demo使用稳定`lessonId/序号`，避免无必要重排已有数组；有重排必须映射旧ID。修改任务或播放器后按原生成器自然失效，禁止仅换fingerprint把历史画面变成新通过。

每条新人工记录至少含：task、variant、stance、fromEdge（适用时）、准确time或播放区间、view、实体/骨架、播放器速度、循环模式、输入版本、实际看到的现象、限制与证据位置。`代码可采样`、`DOM挂载`、`WebGL实际画面`、`有限图审`、`连续播放实际运行`、`真人定性对照`分别保存。自动截图生成和运行计时不能自动授予人工看过。

## 深度交互：完成标准不是动画数量

现有两个专家短弯任务有明确的教学问题，四个引用并不不足；刻滑零新demo也不表示所有四课都必须新造人物。更低维护成本的目标是：每条路线至少有一段能解释其新增技术关系的独立示意，辅以必要对照和可观察诊断，再由完整的证据矩阵约束发布。不能为了填满每课而制造无法被模型支持的受力结论。
