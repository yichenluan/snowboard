# 首批课内三维播放器审阅

日期：2026-10-14。范围是六类型的28个实际引用；全站134个动画引用尚有106个未迁移，另有2个装备交互图。注册表接入不等于教学认证。

## 实现与理由

- 共享 `prototype/motion.ts` 的装备先行、双腿定长与髋求解；每项课程独立编排，不复制旧 SVG 的姿态比例。
- `task` 明确原地、单刃弧线、辅助原地立刃、单弯停止、建刃释放。单弯80%仍渐停，100%才停止并保留工作刃。
- 静态立刃使用固定护栏与双手固定接触，手臂独立求解；不借用动态内倾证明自主站稳。
- 方向线表示移动方向，静止与路线端点隐藏；停止后头部沿最后路线观察，不因零向量突然扭头。
- 模型、平面骨架、俯视和阶段同源。三维失败仍可播放骨架和定位阶段。
- 放大观察使用原生对话框，模型、进度与阶段并排；窄屏顶部保留退出入口。只挂载一个画布，切换前卸载旧实例。
- IIFE、模型、样式随单文件内联，构建缺资源时明确失败。原型 `/3d/` 继续独立发布。
- contentRevision=4，稳定课程ID与个人数据schema不变。旧备份只合并个人记录，避免旧正文覆盖新任务配置。

来源及具体适用条件分别在 [基础研究](lesson-foundations-research.md)、[进阶研究](lesson-advanced-research.md)、[离雪研究](lesson-dryland-research.md)。

### 实际画面与交互

- 中立：较低阶段、斜视、板宽观察、实体与骨架。
- 辅助原地立刃：前后刃保持与恢复；实体可见双手接触同一固定护栏。后刃正常播放到末态停止，不自动循环。
- 高低对照：前刃起点与较高阶段、后刃较高阶段；两腿仍弯曲，实体姿态不同。
- 前后位置：25%前脚侧与75%后脚侧，从板长方向观察；骨盆与胸廓同向，右脚在前及平面骨架均查看。
- 内倾/成角：两对照同35%和板头方向，查看胸廓相对骨盆位置；另看雪靴近景。近景中移出画面的关节标签现在隐藏，不夹到画面边缘误指雪靴。
- 单弯：80%渐停、100%已停住保留后刃；俯视路线与板轴末态一致，末帧移动方向线消失。
- 播放、阶段跳转、键盘End定位末态、视角复位、实体/骨架、前脚切换、放大/收起均使用实际UI。范围输入的自动化fill不触发React更新，因此进度验收使用键盘和阶段按钮。
- 390px窄屏实际查看；不等于真实手机完整手势通过。
