## binding-stance：保留二维与现有三组角度

现有图板头向屏幕右；前脚位于 `x=365`，后脚位于 `x=207`。SVG 的鞋头箭头原始指向屏幕上方，经过正角旋转后其横向分量为正，即指向板头；负角反向，0°垂直板长轴。`[15,-15]`、`[15,0]`、`[24,9]` 与前／后脚标签对应，没有发现正负号反转或标签互换。

最小改进是常显“角度顺序：前脚／后脚；正角朝板头，负角朝板尾”，并将“正常板头”改为“板头”。可加两个淡色 0°参考线，便于在三组之间比较；不需要新增人物左右脚模型，也不把角度改成厂家推荐值。保留已有“数字为几何示例”说明。

## boot-clearance：接触几何存在可复现错误

修正前代码雪面为 `y=231`，旋转支点及板底为 `y=225`。所以板刃与雪面相差 6 SVG 单位，平板时也悬空。靴轮廓为宽 230、高 48、圆角半径 12 的矩形，不应只用外包框尖角判断接触。

对整个圆角轮廓求旋转后的最低点，可得修正前 18 组合中的以下结果：

| 位置／工作刃／倾斜 | 靴轮廓最低 y | 与雪面间隙 |
| --- | ---: | ---: |
| 居中／任一刃／平板 | 213.000 | 18.000 |
| 居中／任一刃／较大 40°示意 | 226.971 | 4.029 |
| 偏脚趾／前刃／小幅 20°示意 | 227.444 | 3.556 |
| 偏脚趾／前刃／较大 40°示意 | 243.041 | **−12.041，靴已穿雪** |
| 偏脚跟／后刃／较大 40°示意 | 243.041 | **−12.041，靴已穿雪** |

这些数值仅用于定位 SVG 错误，不能映射到真实厘米或个人刃角。当前文字始终提示“观察怎样接近雪面”，没有区分已接触状态，会把穿透当成正常可继续倾倒的空间。

### 已落实的修正

1. 将雪面和板底支点统一为 `y=235`；板截面用 `x=190..370、y=225..235` 的直角轮廓，确保示意的低刃是真实接触点，不用圆角板角掩盖支点。
2. 靴轮廓可保持现有宽高与圆角，改为 `x=165+shift、y=171、w=230、h=48、r=12`。增加随横向偏置移动的简化固定器脚床，例如 `x=215+shift、y=219、w=130、h=6`，让靴底—脚床—板面连接可见。文字称“靴与固定器组合的横向位置”，避免看成靴脱离固定器滑动。
3. 每次选择位置、工作刃和倾斜时，计算靴轮廓的真实最低点。若请求角度已超过首次接触，只显示到首次接触并标出接触点，显示“图示已触雪，停在首次接触处”；其余状态显示“本图仍有间隙”。不用布尔提示覆盖一个仍穿雪的图。
4. 保留 0／小幅／较大三档，不给用户显示模型计算的最大角度。图注继续说明比例是作者编排；接触后的卸载、变形与雪板失抓地没有模拟，不能称“安全阈值”或“必然摔倒”。

圆角矩形最低点可由同一解析几何驱动画面和状态：设靴中心为 `(cx,cy)`、半宽高为 `hw,hh`、圆角为 `r`、板刃支点为 `(px,py)`、SVG 有符号旋转角为 `θ`，则

```text
lowestY = py + (cx-px) sinθ + (cy-py) cosθ
          + (hw-r)|sinθ| + (hh-r)|cosθ| + r
```

用 `lowestY=py` 求当前选择范围内的第一次接触，不将靴矩形尖角误作实际圆角表面。接触点的局部坐标同样由该轮廓的支撑点得到，再应用与绘图相同的旋转。修改后示意参数中居中在 40°仍有约 1.09 SVG 单位间隙；偏向当前工作刃的图会在请求到达较大档前触雪。这个差异仅为理解“偏向一侧会减少这一侧空间”，不是装备校准。
