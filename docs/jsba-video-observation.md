# JSBA 与个人八字示范：实际观察记录

日期：2026-10-16。用于本轮课程重构，区分任务规范、官方示范与个人方法。以下均为实际打开原片并查看的有效关键帧；不是仅搜到链接，也不是全片逐帧标定。

原始截图和公开字幕私存工作区 `.research/jsba-rebuild/`，不把完整教材、视频或字幕提交到公开仓库。播放器缓冲、黑屏、旧画面和遮挡严重的截图不纳入有效依据。时刻保留到毫秒，实际帧步进会有约一帧误差。

## S53：JSBA 官方教练检定讲解

[JSBA インストラクター検定](https://www.youtube.com/watch?v=cMgNnGdsmpg)，作者界面确认为 JSBA Official YouTube Channel，片长32:30。片内标题区分 Basic Long、Dynamic Short，讲解包含不同水平的表现与改进意见，不能一律标为满分模板。

### Basic Long

实际帧：115.033、116.033、117.033、118.033、119.033秒。画面有 Basic Long 日文标签。115秒腿相对展开、身体较高；117～118秒膝髋较屈曲；119秒再次展开。支持在此例中辨认展开—屈曲—展开的组织。

对应课程 `s-jsba-basic-carve`：用这些帧理解温和伸展转换和新弧屈曲，不反推每个运动的精确起止，也不把该公开视频等同2025新版教材的完整定义。远机位限制靴、刃与躯干细节；脚角、压力和精确关节角未测。

### Dynamic Short

620.017秒有效画面确认 Dynamic Short 片内标题。另看625.033、625.633、626.233、626.833秒；重点密看630.033、630.333、630.633、630.933、631.233、631.533、631.833、632.133、632.433秒。

旧弧中腿相对伸出，630.633～630.933秒身体紧凑、板经过身下，631.233～631.833秒向下一弧重新展开，随后再收短。它支持“转换收短、新弧重新伸开”的定性组织；不支持只凭头高低判断收腿或压力。

公开日文自动字幕11:47～12:48：讲解先讨论伸展加载与有效立刃，再指出抱腿转换需要更清楚；赶短弯节奏可能只剩一次次伸腿，可放缓节奏使收腿明确。自动识别存在错词，本站只采用和画面、上下文一致的运动方向，不据自动字幕推导评分算法或精确压力。

对应课程 `s-jsba-dynamic-carve`，并支持 `s-jsba-short-carve` 关于先完整再加快的教学归纳。后三者的具体练习顺序和剂量为本站设计。

## S48：MIRATORI 两向转换

[前后刃转换的本人讲解](https://www.youtube.com/watch?v=-ES6HpVWME4)，片长约5:39。是澤田剛志个人八字方法；本人课程明确不以JSBA/SAJ考证技术训练为目的。不能由教练资历把其所有方法变成机构规定。

前刃换后刃：142.033、143.033、144.033、145.033、146.033、147.033、148.033、149.033秒。分屏慢放左侧先重组到板上方附近，约146秒较平板，随后膝髋折叠进入后刃；右侧编排对照更久留在旧侧。

后刃换前刃：247.791、248.191、248.591、248.991、249.391、249.991、250.591、251.191、251.791秒。左侧旧后刃折叠后腿相对展开，骨盆离开脚跟侧，胸廓允许前倾以协调新前刃。两向不能机械镜像，躯干也不是永远竖直。

公开字幕4:43附近本人明确这是自己的风格、存在多种方法。这两段更适合观察展开转换，不能用来证明所有低位都收腿换刃。分屏不是严格对照实验；没有压力、板弯、脚角或速度测量。

对应 `s-carve-expert-variation.videoStudy` 两段。只支持所列可见关系及据此作出的教学归纳。

## S52：MIRATORI 前刃原地对照

[前刃技巧](https://www.youtube.com/watch?v=TwjZvBUY7hU)。实际看130.033秒原地折胸示意、195.033秒原地髋部参与示意，以及280.033秒靴前部关系示意。原地讲解没有双脚固定滑行；不能把静态姿态冻结成动态模板，更不能从口述压力位置推断实测脚下压力。

片头另看10.033、10.433、10.833、11.233、11.633、12.033秒的较低滑行。雪雾和剪辑明显，其中11秒附近切换镜头；不能串成完整连贯换刃证据。

`s-carve-expert-review.videoStudy` 只采用130.033与195.033秒两帧，帮助区分“头低”和“髋参与”。两帧并非连续动作，不能用其间65秒作为一段滑行。具体支撑要回真实单弧和现场观察确认。

## S54：MIRATORI 较低后刃

[八字后刃技巧](https://www.youtube.com/watch?v=FookVR1Ojuw)，实际看5.033、5.433、5.833秒同一镜头；另看6.233、6.633秒切换后的镜头。前一窗口可见膝髋折叠、骨盆位于脚跟侧较低、胸廓相对配合与手触雪，雪雾遮挡部分靴板细节。

广角跟拍有透视畸变；无法确定手部支撑量、压力分配或关节角。6秒后镜头已经切换，不当成连续转换。490秒截帧仍在缓冲，未作为依据。

对应 `s-jsba-duck-mechanics.videoStudy`：区分板宽方向屈髋和沿板长坐尾。触雪是个人风格结果，不是本站要求，也不能依一张低位画面证明完整弧线质量。
