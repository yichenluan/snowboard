# JSBA 刻滑体系与本站学习路线对照

核对日期：2026-10-16。本站基线为 `main` 的 `57a3905`，课程内容版本 20。本报告比较现行公开规范、可核查的历史教学资料与本站实际课程、能力图和播放器；不改变网站课程或动作。

这是改造前的调研快照。后续已按双主线重构网站，当前结果见[重构审查](jsba-restructure-review.md)和[验证与发布](jsba-restructure-release.md)，下文“本站尚无”均指上述旧基线。

## 直接执行

**本站与 JSBA 在抓雪、弧形、速度控制和身体可调等目标上有大量共通。主要差异在课程组织与专项覆盖：JSBA 保留明确命名的 Basic、Dynamic 示范任务，并独立考查刻滑短弯；本站按结果能力递进，重点发展专家大弯，另设低姿态 duck 选修。本站尚无完整的纯刻滑短弯路线，也没有独立的屈曲式连续刻滑示范。**

“JSBA 八字刻滑体系”需要拆开理解：八字是固定器前正后负的站姿；JSBA 是包含多种站姿、教学技术与考核任务的体系。当前公开证据不支持把它缩写成一套强制八字、低位或触雪的统一滑法。

### 名称与版本

这里沿用本站定义：八字指 duck stance，前脚正角、后脚负角，不要求正负等角，不指数字 8 的路线。

JSBA 官方第 21 期示范者页面同时列出不同设置：田口瑞树为前 36°、后 15°；藤巻俊介公布的范围为前 12–30°、后 −9–9°，跨越八字、正零与双正。它们是个人装备资料，不能据此推荐学习者照搬，但足以说明 JSBA 的示范者并非统一八字站姿。[JSBA 官方示范者与装备](https://jsba.or.jp/education/demonstrator/)

JSBA 于 2025 年出版新教程，并明确从 2025 年 9 月起，全部讲习和检定使用新版；2026 年 10 月官方公告仍沿用这一安排。本轮以此为版本基准，旧教程时期的技术名称和示范只作有日期的参照。[新版使用公告](https://www.jsba.or.jp/news/detail/440/) · [2026 年 10 月教育公告](https://www.jsba.or.jp/yukibouzu/web_yukibouzu/wy202610/education/ed-11.html)

2025 新教程的公开目录是导入、基础、发展、应用技术等部分，范围远大于刻滑。**本轮未取得新版教材完整正文与 DVD，因此以下能确定的是公开任务、评价目标及部分动作框架；不能声称完成新版逐页、逐姿态比较。** [教材出版信息](https://www.yamakei.co.jp/products/2822460300.html) · [DVD 出版信息](https://www.yamakei.co.jp/products/2824875770.html)

### JSBA 的三类要求应分别比较

**第一类是分级技术检查。** Badge 的公开任务体现从连续转弯、长中弯，到刻滑长弯、刻滑短弯及 Basic 示范的能力层次。它是考试任务清单，不能直接冒充完整逐课教学大纲。[Badge 官方任务表](https://www.jsba.or.jp/education/badgetest/)

| 级别 | 与本次比较有关的任务 |
| --- | --- |
| 5 级 | 连续转弯，板头朝坡下后停止 |
| 4 级 | 长弯、中弯 |
| 3 级 | 刻滑长弯，短弯；后者名称未指定为刻滑 |
| 2 级 | Basic 长弯，刻滑短弯，自由滑行 |
| 1 级 | Basic 长弯，Basic 短弯，自由滑行 |

能力顺序可供参考，但并非所有人必须从 5 级逐级报考；官方允许从 2–5 级任一级开始，报考 1 级则需已持 2 级。也不能把 JSBA 1 级与 CASI 某个等级按数字直接换算。[官方报考说明](https://www.jsba.or.jp/education/badgetest/)

**第二类是能清楚示范指定动作的教练要求。** 2026 年 9 月版教育规程的别表 A-1（PDF 第 12 页）仍列出 Basic 长弯、Basic 短弯、Dynamic 短弯，另有滑移中弯、自由滑行和跳跃。它同时检查动作时机、抓雪、稳定速度和均匀弧线，不能只凭明显上下起伏判断完成。[现行教育规程](https://www.jsba.or.jp/education/rules/pdf/education_rules.pdf)

**第三类是高质量滑行表现。** 官方明确区分：教练考试含较多指定运动，TECH.TEST 不指定运动方式，重点是刻滑质量、转弯控制和整体平衡。因此“Basic 要演示上下运动”不能推导成“所有 JSBA 高级刻滑都必须这样换刃”。[TECH.TEST 与教练考试的区别](https://www.jsba.or.jp/education/badgetest/)

2026 年第 33 届技术选的自由刻滑、长弯、中弯和短弯也均无演技指定。其评价强调使雪板有效弯曲、控制弧形与尺寸、在弯中保持速度；仅切换刃、依赖侧切滑行，或以接近直滑降的浅弯追求速度，均不足以取得高评价。这是竞赛目标，不能直接套给刚学浅刻滑的学员。[第 33 届技术选规则](https://www.jsba.or.jp/ajstc_site/ajstc33/regulations.html)

### 主要技术名称怎样对应

下表中的中文是为比较而作的解释，不宣称是 JSBA 官方中文译名。尤其要把身体运动、压力变化和雪板反应分开。

| JSBA 名称或概念 | 已核查资料支持的含义 | 本站对应及覆盖程度 |
| --- | --- | --- |
| ベーシックカーブ，Basic | 现行教练任务仍要求合适的上下运动。2021 年公认学校记录使用“立ち上がり抜重／沈み込み荷重”口令，强调以腿屈曲而非折腹腰 | 本站低姿态示例采用温和伸展过渡、弯中小幅屈曲；尚未核实它与新版 Basic 的具体时序、方向和条件是否相符，不能直接改名 Basic |
| ダイナミックカーブ，Dynamic | 现行考试保留该任务；历史官方规则将 Basic 与 Dynamic 的展开对应起身系与抱腿系运动 | 本站文字承认屈曲、回收或组合过渡，也有通用单次转换练习；未形成独立的屈曲式连续刻滑任务，不能据原则提及便算完整覆盖 |
| プレスカーブ，Press | 2013 年官方指定任务强调较多跨侧运动、利用外力，并尽量避免急剧卸压，压力强弱仍会变化 | 可与本站连续连接、避免突兀动作的目标比较；没有对应专项。它是历史任务，不能写成当前每位学员的必修终点 |
| ストローク，腿部屈伸 | 公认学校用它调节滑行，服务弯形、速度和坡面变化；不是只移动上身 | 本站将踝膝髋配合、开始屈伸、持续和收住分开解释；高度不直接等于压力 |
| 角づけ，立刃 | 历史与现行规则均把它放在弧形、雪况、速度和内外力关系中评价 | 本站同样使用内倾与关节配合立刃；进入新刃不等于立刻加到最大角度 |
| 回旋，身体与板的转动协调 | 历史中弯规则明确按坡度、速度和雪质组合立刃、压力与 rotation；新版勘误保留并纠正“回旋”一词 | 本站允许肩髋自然协调，减少的是破坏窄痕的多余转板。身体旋转与雪板横扫不是同一个观察量 |

动作依据分别为：[公认学校 2021 年 Basic 训练](https://asahiprime-snowboardschool.jp/basiccurveshort/)、[现行教练任务表](https://www.jsba.or.jp/education/rules/pdf/education_rules.pdf)、[2014 年第 21 届起身系与抱腿系展开](https://www.jsba.or.jp/ajstc_site/ajstc21/rules.html)、[2013 年 Press 指定任务](https://www.jsba.or.jp/ajstc_site/ajstc20/competition.html)、[2025 新教程勘误](https://www.yamakei.co.jp/products/b5ad0a0ad552939e5e98233630d1c2f7.pdf)。

新版勘误将 lean-out 的支点说明补为腰或膝，包括前刃相关句子。这支持不要只用腰部一种动作解释反弓，却不足以给出全体滑手统一的髋膝角度、肩髋朝向或前后脚压力公式。[出版社勘误 p.30](https://www.yamakei.co.jp/products/b5ad0a0ad552939e5e98233630d1c2f7.pdf)

### 本站实际学习路线

本站目前没有 JSBA 注册来源；基础机制主要综合 CASI、SBINZ、AASI，专家刻滑任务主要参照 CASI，duck 定义及装备说明使用 Burton。以下顺序来自实际 `content.json`，并非只复述旧交接。

基础与专家主线是：

1. `v20-carve`：刻滑和搓雪，主动选择滑移多少。
2. `v-toe-low-drill` 与 `v-heel-brief-hold`：两侧独立单弧。
3. `s20-rails`：连接浅弧窄痕，按计划结束。
4. `v20-path` 与 `v-toe-touch-criterion`：路线、自查和后续选择。
5. `s-carve-expert-arc` 与 `s-carve-expert-pressure`：落线前建刃、出口，以及屈伸与换刃时机。这两项在能力图中并列精修。
6. `s-carve-expert-variation` 与 `s-carve-expert-review`：条件迁移和完整复盘。

低姿态八字是另一分支：固定器角度 → 靴居中与拖靴检查 → 前刃、后刃分别做高低对照 → `s-duck-low-linked` 连续两侧转换 → 进阶条件中的低位应用。它依赖正常高度下已有的刻滑控制，不强制反脚刻滑，也不把回收换刃作为入门前置。

源码定位：[刻滑与低位路线](../content.json#L20441)、[能力前置](../content.json#L18885)、[duck 连续课程](../content.json#L15447)。本地编辑器可按上述稳定 ID 搜索；GitHub 展示时行号可用于定位。

本站高阶参照是 CASI 的 Expert Large Radius Turns (Carving)：7–15 米走廊、压雪地形、专家速度，落线前建立刃上平衡，以立刃和调压塑造弯形，控制出口并维持刻滑路径。该项并不规定 duck、最低身体高度或摸雪。[官方 Riding 指南 p.7](https://members.casi-acms.com/documents/Riding_LV4_EN.pdf) · [本站课程设计](level4-carving-curriculum.md)

### 两项已确认的覆盖缺口

**一是纯刻滑短弯。** 本站已有普通和专家搓雪小回转，但正文自己也说明“普通搓雪小回转允许滑移，纯刻滑小弯另有条件，应分别练”。现有小回转动作使用 `round-linked-skid` 等任务，保留板轴与运动方向的夹角；弯小不代表刻滑。目前没有对应的独立刻滑短弯课程、能力结果和完整递进。

核查位置：`content.json` 第 7314 行的小回转说明、第 20441 行的刻滑目录、第 20459 行的小回转目录；`lesson-player/short-turns.ts` 第 25、66 行。

**二是换刃策略从原理到连续刻滑的衔接。** 专家刻滑文字允许已掌握的伸展、屈曲或组合过渡，低位与专家课也链接 `v13-down-drill`。但后者是通用单次转换；专门连续回收课 `v17-retract-drill` 使用的是 `linked-retraction-skid`。duck 刻滑播放器切换正常、较低与探胸姿态，没有独立换刃策略；专家刻滑的屈伸偏晚对照也不等于 Dynamic 或抱腿式换刃。

核查位置：`content.json` 第 5902、7442、15494、17146 行；`lesson-player/carving.ts` 第 6、35、47 行；`lesson-player/expert-carving.ts` 第 4、19、40 行；`lesson-player/coordination.ts` 第 24 行。

因此准确结论是：**本站讲过多种策略，也提供相关工具，但没有把它们完整组织成可独立学习、连续观察和验收的屈曲式刻滑路线。** 这与“完全没讲”或“已完整覆盖 JSBA Dynamic”都不同。

## 深度交互

### 网站最值得吸收的部分

**先补专项覆盖，再补风格外观。** 如果目标是让本站覆盖更完整的刻滑能力，优先级最高的是纯刻滑短弯，以及伸展式、屈曲式转换在连续刻滑中的独立训练。现有搓雪小回转和通用回收练习可作基础，但不能通过改标题获得刻滑能力。

更低成本的课程设计，是保留现有单弧、浅弧与专家大弯主线，在已有正常高度刻滑后增加“换刃策略比较”，再发展刻滑中短弯。低姿态仍作为并行应用。这里的新增顺序是本站设计建议，不能包装成 JSBA 官方课表。

**把“能留窄痕”和“能主动塑造高质量弧线”分开。** 浅刻滑可以作为入口，但进阶时应明确比较：能否在相近条件下改变弧形、保持抓雪、控制出口，并管理板的响应。JSBA 的高阶判据能帮助检视这一跃迁；本站专家课已有对应文字，下一步价值在真实示范和可观察结果，而不是重复增加“压板”口令。

**考证分支需要独立标准。** 若目标包括 JSBA Badge 或教练考试，应另做任务映射，标出指定动作、地形、弯数、观察点与官方来源。它可以复用能力基础，但不宜把所有普通学员都导向教练示范要求。

### 当前不应作出的改动判断

现有证据不足以要求全站采用统一八字角度、固定开肩幅度、每弯固定前中后压力配比、触雪标准，或“先伸展后回收才算高级”的单一终点。也不能因为本站采用 CASI 的无 pivot 刻滑任务，就宣布它与 JSBA 回旋概念冲突。

若要进一步比较某一种“日式八字低位”的具体动作，比较对象需要收敛到具名教练、课程或示范片段，并说明其装备与滑行情境。机构名称本身无法替代这些动作条件。
