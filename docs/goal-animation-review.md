# 本轮教学动作与播放器审查

日期：2026-10-15。对应任务为系统审查与升级；入口清单见 [教学审查表](teaching-audit.md)，正文研究见 [小回转](goal-short-route-review.md) 和 [低姿态八字](goal-duck-route-review.md)。

## 新增动作规格

| 项目 | `duck-carve / linked-duck-carve` |
| --- | --- |
| 关联课 | `s-duck-low-linked`；正常高度刻滑通过后，先两刃单弧高低可调，再连续转换 |
| 要回答的问题 | 在已有可控刃线内，降低姿态改变了什么；前后刃为何不镜像；怎样保留两次释放与恢复空间 |
| 来源定位 | CASI Reference Guide p.49–52、155；AASI Performance Guide v2.0（2022-11-07）p.3、5、15；站姿定义与非对称来源见专项研究 |
| 情境 | 软靴、前正后负 duck stance，平整缓坡上的正常高度→较低→正常高度练习；本示意没有真实滑速/雪况解算 |
| 站姿假设 | 模型固定器 +18°/−9°、站距0.54m，为作者装备示例，非用户处方；右脚在前镜像全部装备、身体与路线 |
| 阶段 | 后刃已释放→近平板→渐建前刃→弧中较低位置→完成并释放→近平板→渐建后刃→弧中较低位置→恢复释放余量→下一次前刃 |
| 两腿任务 | 各自固定脚向约束下连续屈伸，行进前腿参与前段引导、后腿续接，保留两脚之间的调整；无固定承重比例 |
| 前刃关系 | 膝、骨盆与躯干协调调整，胸廓不抢先扑入；不靠翘脚跟或腰椎反弓制造姿态 |
| 后刃关系 | 膝髋折叠、骨盆脚跟侧、胸廓相对回板，靴/高背连接保留；不把脚跟侧与板尾混同 |
| 路径和板角 | 两弧连续路径；板轴为水平路径切向，正弦刃角；正常/较低/探胸三种姿态共用板路径。几何端点轨迹不是真实雪痕 |
| 压力表达 | 不绘制压力百分比、牛顿值或肌肉激活；骨盆高度不是压力，近平板不是零压力 |
| 参考/反例 | normal↔low 对照高度；reach 只在 low 基础上增加前刃探胸，与 low 同腿长对照。固定路线仅为隔离变量，不证明错误姿态也能保持刻滑 |
| 教学简化 | 温和伸展过渡只是本例，回收仍是选修；低姿态为逐步降低第一步，非极限深蹲或摸雪示范；身体非动力学平衡求解 |
| 未核验 | 连续实拍标定、个人适合的幅度、靴材料、真实接触/抓地、足底压力、肌肉作用、全表面精细穿插 |

实现位于 `lesson-player/carving.ts`，使用既有固定脚位、骨长与装备约束。新增类型直接注册到课内运行时，清单取旧预设与新注册表并集；不伪造一套旧 SVG 动作来满足迁移统计。

## 本轮发现和修复

| 级别 | 证据/问题 | 修复与验证 |
| --- | --- | --- |
| P1 | 原站没有连续低姿态 duck 任务，单刃高低/普通浅弧不能代替 | 独立任务与新课；两刃分别编排，保留正常高度基准和退出条件 |
| P1 | 初版探胸反例以 normal 为参考，腿长与胸廓同时变化 | reach 改与 low 同帧对照；浏览器检查参考标签与保留进度，几何测试检查同路线/脚位 |
| P1 | 初版前刃高度差不易看见，进一步屈腿又可能把差异转给胸廓 | 前刃、后刃分别安排适量降低，减少前刃躯干补偿；检查实际骨盆、膝、胸廓关系和实体画面，不以一个角度过关 |
| P1 | 初版线性正负半波造成换侧关节相对板的速度折点 | 姿态权重改为半波平方；雪板刃角保留原连续曲线。刚体低刃支撑高度的换侧几何近似单独保留，不硬平滑到穿雪 |
| P2 | 精确点击阶段起点，浮点误差可使“渐建后刃”仍显示近平板 | 目标落在对应分类区间内，测试直接采样按钮 `at` 而非绕过边界 |
| P2 | “弧中降低”标签后半段实际已恢复腿长 | 改为“观察较低姿态”，解释进入并离开较低位置 |
| P2 | 完整/分段循环互切只取消旧选项；更换任务后旧范围仍可能保留 | 两模式直接切换，动作配置变化清除旧循环，拖动进度退出；浏览器实际操作覆盖 |
| P1 | flex/retract小回转被开放到不支持的急甩尾组合，切换会抛出错误 | 只给默认/extend开放同步对照；实际课程配置回归测试及三门受影响课浏览器复验通过 |
| P2 | 路线开关含义宽于实际作用范围 | 改名“俯视路线图”，同时控制通常与同步对照图；三维地面路径保持作为场景参照 |

所有课内播放器支持基准/教学强调、键盘进度、阶段跳转、速度与教学重播。强调仅增加同源骨架/平面观察，支持对照的任务增加同步参考；不放大身体幅度，不改变动作时序。分段回跳明确为教学重播，不是让雪上动作倒滑。没有给所有动作机械添加受力箭头。

## 实际观察与自动检查的区别

- `page-access.json`：Chrome 实际打开103个课程 hash，核对标题与练习区存在。这证明可访问，不证明教学已核验。
- `render-results.json`：135项引用去除标题/提示/时长等元数据后，按93个展示配置逐配置实际创建 WebGL 画布，取0、25%、50%、75%、99.9%共465张图；保存引用映射与当帧工作刃/文案。不是135条各自不同的动作。
- `sheet-00`—`sheet-30`：上述截图联系表。三个审阅者分担0—29、30—59、78—92，主审看60—77；均仅记为有限画面审阅。未凭这些图确认新的几何P0。
- 五等分采样会漏掉转换：例如026、043、047、057、058、086的部分关键事件不在这些时点。核心与代表性前置额外按实际阶段取帧；其余未补齐的过渡保留待查，不能把465张图等同全站逐帧验收。
- `core-flow-results.json`：1440×1050桌面、390×844窄屏、术语别名搜索、来源展开与同源引用定位、目标与前置、同帧切换、循环切换、放大/ESC、键盘拖动、俯视图开关、旧记录保留与新增能力不自动通过、实际禁WebGL后可播放骨架。窄视口不是实体手机测试。
- 自动几何测试检查脚位、骨长、姿态对照同路线、实际刃事件、周期平移接续及水平路径/运动方向；它们不等于教练认证或真实受力验证。

本轮原始截图、运行日志与采样JSON在忽略目录 `.validation/goal-audit/` 和 `log/goal-*`，不把完整第三方教材或个人记录放进公开仓库。逐项可持续状态及证据定位由教学清单保存；最终工程测试、发布和边界汇总另见 [本轮交付](goal-upgrade-review.md)。

核心额外实际观察：026两惯用脚58帧；043/047/057/058两惯用脚112关键帧（覆盖每配置、每站姿的前两次双向转换）；092两惯用脚×正常/较低/探胸108密帧，以及54张侧面、沿板头、靴部视图。转换中腿长调整、前后刃差异和同腿长探胸对照可辨，所看帧未见新确认P0/P1。原始记录 `core-short-visual-review.json`、`core-duck-visual-review.json`；仍标partial，不称完整连续实拍标定。
