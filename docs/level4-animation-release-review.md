1. 长六弧完整路线缩小后太窄：增加同源当前弧段局部图，完整滑段可展开。范围由任务返回世界z区间，未改变路线或隐去方向夹角。

3. 100%“循环当前段”只重播约几十毫秒近平板，近似静止：终点可指定有教学意义的重播区间。刻滑重看最后完整一弧，小回转重看完整回宽恢复；普通阶段仍按自身真实事件边界重播。增加独立播放回归测试。
4. 固定世界通道的边界统一灰色，使局部与完整路线的图例一致；不再按可见区段的临时索引换色。
