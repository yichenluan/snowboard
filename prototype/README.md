# 搓雪小回转三维原型

此目录独立构建为站点的 `/3d/`。只打开原型才加载 Three.js；原教材仍是可离线使用的单文件 HTML。

## 维护分工

- `motion.ts`：以米为单位的统一世界坐标、雪板状态、固定脚位、双腿 IK 与轨迹。这里不读取画布尺寸或镜头参数。
- `scene.tsx`：将同一状态显示为三维人偶与俯视图；镜头只改变观察方向。
- `lesson.ts`：三种模式、四个阶段、两侧工作刃的同步说明、练习进阶和资料来源。
- `main.tsx`：单一时间线、暂停/循环、模式对照、左右脚、图层与视角。
- `styles.css`：桌面、手机和打印布局。

## 动作约定

世界 x 为横坡、y 为雪面法向、z 为坡下；板局部 x 指向板头。所有关节输出世界坐标，不再次乘雪板变换。两脚固定在板上，两腿各自求解；右脚在前完整镜像。

`sampleMotion(time, mode, stance, hold)` 的时间是两弯周期。`time=1` 表示下一周期的下坡平移位置，因此播放器停在 100% 时用 `1-1e-6` 保留第二弯末态。循环播放按周期重置，路线与姿态不从屏幕像素反推。

反例只刻意突出前半段直冲、随后快速增加板轴与移动方向的夹角，不代表所有小回转错误。侧滑练习缩短等待时保持连接单弯的几何不变。

## 教学边界

这是按教学依据编排的运动学示意，不是雪板与雪面的动力学求解器。力箭头仅表示作用方向，长度不表示大小；重力方向采用示意缓坡坐标。骨盆移动箭头不表示发力方向。人体质心按身体分段位置粗略估计，不能用于推断足底压力或肌肉激活。

增加动作时，先核验教学来源与能力前提，再补动作数据和分阶段文案；不要通过改变镜头或单独绘制俯视小人掩盖姿态错误。几何与文案检查在根目录 `tests/`。

## 验证与发布

在仓库根目录执行 README 中的类型检查、测试和构建命令。浏览器检查正确/错误同进度切换、两种前脚方向、三个练习等级、100% 末态，以及手机显示。`git push origin main` 后由 GitHub Actions 构建并发布。
