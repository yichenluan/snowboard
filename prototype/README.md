# 搓雪小回转三维原型

此目录独立构建为站点的 `/3d/`。人物和装备约束、场景也由 `lesson-player/` 复用；课内三维另构建成内联 IIFE，随单文件教材保存。动作时序和教学任务各自编排。

## 维护分工

- `motion.ts`：以米为单位的统一世界坐标、雪板状态、固定脚位、受雪靴约束的小腿、双股骨求髋与轨迹。这里不读取画布尺寸或镜头参数。
- `scene.tsx`：将同一状态显示为三维人偶与俯视图；镜头只改变观察方向。
- `lesson.ts`：三种模式、四个阶段、两侧工作刃的同步说明、练习进阶和资料来源。
- `main.tsx`：单一时间线、暂停/循环、模式对照、左右脚、图层与视角。
- `styles.css`：桌面、手机和打印布局。

## 观察与镜头

所有预设视角都支持鼠标拖动旋转和滚轮缩放。预设按钮是观察起点；再次点击同一预设或“重置视角”即可复位。播放、暂停或拖动进度时，镜头跟随雪板位移，同时保留手动选择的观察角度与距离。

“触屏旋转”默认关闭，手指在画面上纵向滑动会滚动页面。开启后，单指旋转模型、双指缩放；关闭后恢复页面滚动。该开关不影响鼠标操作。

## 动作约定

世界 x 为横坡、y 为雪面法向、z 为坡下；板局部 x 指向板头。所有关节输出世界坐标，不再次乘雪板变换。两脚固定在板上，小腿先由靴底坐标与有限前倾生成，再用双股骨长度和髋宽求骨盆；右脚在前完整镜像。

`sampleMotion(time, mode, stance, hold)` 的时间是两弯周期。`time=1` 表示下一周期的下坡平移位置，因此播放器停在 100% 时用 `1-1e-6` 保留第二弯末态。循环播放按周期重置，路线与姿态不从屏幕像素反推。

反例只刻意突出前半段直冲、随后快速增加板轴与移动方向的夹角，不代表所有小回转错误。侧滑练习缩短等待时保持连接单弯的几何不变。

## 教学边界

姿态用于编排教学中的关节、身体与板刃关系，尚未根据实拍动作标定。它是运动学示意，不是雪板与雪面的动力学求解器，也未经过生物力学认证。力箭头仅表示作用方向，长度不表示大小；雪面作用箭头起点不是压力中心或几何低刃；重力方向采用示意缓坡坐标。骨盆移动箭头不表示发力方向。人体质心按身体分段位置粗略估计，不能用于推断足底压力或肌肉激活。

增加动作时，先核验教学来源与能力前提，再补动作数据和分阶段文案；不要通过改变镜头或单独绘制俯视小人掩盖姿态错误。根目录 `tests/` 中的检查验证关节约束、前后刃的身体位置关系与文案一致性；这些检查不构成实拍标定或生物力学认证，也不能单独证明动作适合所有滑手与雪况。

## 验证与发布

在仓库根目录执行 README 中的类型检查、测试和构建命令。浏览器检查正确/错误同进度切换、两种前脚方向、三个练习等级、100% 末态，以及手机显示。镜头检查覆盖默认拖动与缩放、播放时保留手动角度、重复点击预设复位，以及触屏旋转开关与页面滚动。`git push origin main` 后由 GitHub Actions 构建并发布。

## 2026-10-14 后刃与转换复核

[教学研究与照片定位](../docs/teaching-research.md)记录来源和证据边界，[原型审阅记录](../docs/prototype-review.md)记录缺陷、模型与验收。[全站清单](../docs/animation-inventory.md)由 `node scripts/inventory-animations.mjs` 生成；使用 `--check` 检查同步。

本版先固定靴底，再用有限靴筒前倾生成两膝，以固定股骨长度及髋宽求骨盆。高背独立固定在固定器坐标。示例靴筒相对鞋底法向前倾12–18°、高背前倾12°，仅是所选装备模型，不是临床踝角或雪靴通用范围。correct 刃角峰值约13.75°，也不是教学目标角度。

前换后与后换前分开讲解。侧滑接弯的屈伸只包含一次过渡，末段标为恢复侧滑。新增六个转换检查按钮，其时刻由实际动作模型求得；新增雪靴与高背近景。`?t=0.84` 可打开指定进度（0–1），默认停在后刃控制段供审阅。

仍未完成教练实拍逐帧标定，不模拟真实压力或肌肉激活。独立原型三模式仍采用刚体板；共用模型已增加可选局部板面，仅由课内扭板任务使用，详见[反脚与扭板研究](../docs/lesson-switch-twist-research.md)。正文与画面尚未取得教练认证。全站现有动画引用已完成本地迁移，准确覆盖、发布状态与剩余验证见 `docs/animation-inventory.md` 和 `docs/lesson-player-review.md`。
