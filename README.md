# 单板滑雪 · 进阶技术手册

面向已有基本滑行能力、想继续打磨技术的单板滑雪者。讲清楚身体怎么配合、动作什么时候发生，以及怎样从弯形、板痕和滑行感受判断练习是否有效。

**[打开在线手册 →](https://jinke.me/snowboard/)**

## 适合谁

如果你已经能用前后刃控速、主动停止、连续转弯，并能避让来人，可以从这里继续练习。内容主要围绕软靴单板在压雪雪道上的技术，适合上雪前准备、滑行后复盘，也可以带着具体问题和教练一起看。

## 两条进阶主线

### 搓雪小回转：把短弯滑得连续、可控

从稳定的中弯逐步缩小弯形，练双腿引导、屈伸配合、旧刃释放和连续控速，再发展到 CASI（加拿大单板滑雪教练协会）四级专家小回转任务中的技术要求。

重点是弯形和节奏始终可控，能按需要放大弯或结束滑段。搓雪小回转可以独立练习，无需先学会纯刻滑。

[进入小回转路线 →](https://jinke.me/snowboard/#route=short)

### 刻滑：从干净弧线到低姿态八字

先建立正常高度下可靠的前后刃弧线，再参照 JSBA（日本单板滑雪协会）的技术体系，练习起身式与抱腿式转换、弯幅变化和纯刻滑短弯，逐步应用到八字站姿下的高低控制与低姿态连弯。

“八字”指前脚正角、后脚负角的站姿。低姿态八字是本手册的应用方向；JSBA 并不统一要求八字站姿、蹲到最低或触雪。降低身体时，仍要保留抓雪、换刃和恢复正常高度的能力。

[进入刻滑路线 →](https://jinke.me/snowboard/#route=carving)

## 手册里有什么

- **动作原理**：站姿、立刃与放刃、内倾与反弓、屈伸时机、下肢引导和肩髋配合。
- **具体练法**：每课说明目标、前置能力、适用条件、操作步骤、自查方法与退回更简单练习的信号。
- **三维动作示意**：慢放、分阶段观察、切换视角；部分课程可比较前后刃、左脚或右脚在前，以及不同动作方式。
- **问题诊断**：从弯形、板痕和失控发生的阶段查原因，再选练习验证。
- **辅助内容**：反脚、装备调整、热身与体能，以及可检索的术语解释和资料出处。

## 建议这样开始

1. **先核对基础。** 从[共同基础路线](https://jinke.me/snowboard/#route=foundation)检查双刃控制、圆弯和两向换刃，再选择进阶方向。
2. **一次聚焦一个问题。** 用首页能力图选择下一步，或搜索当前遇到的现象，先看课程的适用条件与目标。
3. **先看完整动作，再拆阶段。** 用三维示意观察腿、髋、上身与雪板的关系，把前后刃分开看。
4. **回到雪上看结果。** 按课程练习并自查弯形、板痕和控速；沿路线进入课程后，可按前后课继续学习。

能力图的勾选用于自查。是否进入下一步，以实际滑行表现为准。

## 资料与动作示意怎么看

课程引用 CASI、JSBA、PSIA-AASI、NZSIA / SBINZ 等机构资料，并在课内注明出处。协会原始要求、本站整理的练习方法与个人经验分别说明；学习某项技术不等同于取得相应教练资格。

三维动画用来帮助理解姿态、路线和动作时机，画面中的角度、身体高度和播放速度是示意参数。观察时请结合课程条件、自己的滑行结果与教练反馈，不把某一帧外形当成所有人都要照搬的标准。
